二、工件条件与排刀表（上机前务必核对实机刀位与落刀距）
- 工件材料与毛坯 : 塑料棒（按 POM 等通用工程塑料估算参数），棒料直径 DIA18.5 mm，干切不开切削液（全程序无 M08，仅保留首尾 M09 保底）
- 加工模式       : 仅 Path 1 主轴程序（无副主轴同步接料）
- T0101 : 前刀架横向动力头，DIA6.0 mm 中心刃平底立铣刀（实核落刀距，前按 16.0 mm 估算）
- T0606 : 60度外螺纹车刀（M8.0*1.0 5度锥螺纹）
- T0707 : 35度外圆车刀（按理想刀尖编程，不开刀尖 R 补正；刀补表 R 设 0）
- T0808 : 2.0 mm 宽切断刀（较小 Z 零件侧刃对 Z0，刀宽向 +Z 伸；10mm 刀柄默认 G150 Z9.900 留 0.1 mm 平端面余量）

三、核心修正项汇总
1. 开机初始化、干切与行程保护：
   - 补齐 M94/M60/M11/G300/G150/M61/M10 夹头松夹与送料闭环，停主轴 M05 移至 G300 之前，G300 后先退至 Z-2.0 / X38.0 再换刀。
   - G300 暂留空为 G300 Z____ T0808 待上机实核；注意预警：若实机 G300 Z 上限为 40.0 mm 且 T0101 落刀距为 16.0 mm，则腰槽最大刀心 Z30.3 + 16.0 = 46.3 mm 将超出 40.0 mm 行程上限，须实核实机落刀距或改用二次送料/换短落刀距刀位。
   - G150 Z9.900 保留 0.1 mm 平端面余量（较小 Z 侧刃对 Z0 + 10mm 刀柄，上机按实机刀柄规格复核）。
   - 全程序已移除 M08 切削液开启指令，仅保留开机与程序尾 M09 保底关液。
2. 外圆粗精车（T0707）：
   - 按练习规范统一采用理想刀尖编程，不开 G41/G42 刀尖半径补正，直接采用简洁标准的 G71 + G70 P110 Q190 完成粗精车（去掉 G70 行尾非标 F，由 G70 自动读取 N110-N190 段内 F0.060）。
   - G71 起刀 X19.500、终点 X18.800（满足 X_end+U=19.1<=19.5 且完全脱出 DIA18.5 毛坯）；轴向余量 W-0.050。
   - 前端改为 C1.0x45度引入倒角（起点 X6.200 低于 Z0 螺纹底径 6.696，交汇 5度锥面于 X8.171 Z0.985），彻底避免车牙后前端倒角被切没。
   - DIA16 肩部 R0.60 圆弧由 G03 修正为 G02（防止内凹啃槽）；45度斜肩 R0.50 展开为显式圆弧 G02 X13.000 Z12.207 R0.500（不依赖 `,R` 直接图纸选配）。
3. 5度锥外螺纹（T0606）：
   - 螺纹终点提前至 Z9.000（距 Z10.41 45度斜肩预留 1.41 mm 安全距，兼顾约 8 扣有效牙与防撞肩）；锥度半径差同步重算为 R-0.962（L=11.0），7 刀终径 X8.270。
   - 转速由 S800 降至 S600 减小 Z 轴退尾伺服过冲；循环退刀径抬高至 X14.000（高于 DIA13 台阶），并移除未核实的 M34/M35。
4. 横向铣腰形盲槽（T0101 DIA6.0 + O8105/O8106）：
   - 适配 DIA6.0 中心刃立铣刀重新计算槽宽 R3.30 轨迹：粗铣 O8105 为 Y+-0.150 / R0.150（单边留 0.15 mm），精铣 O8106 为 Y+-0.300 / R0.300（槽宽 6.60 mm 到位）。
   - 内弧按刃口线速度折算降速（O8105 内弧 F15，O8106 内弧 F20），精铣采用 90度切向圆弧切入/切出消除精壁接刀痕。
   - 采用 Z24<->Z30 双程温和斜坡下刀（4.2~5.7度，单程 ap=0.44~0.60 mm），回零前先 M83 松刹车、M23 S4000 后加 M312 到速确认。
5. 切断与大端 R0.50 倒角（T0808）：
   - 统一按“较小 Z 零件侧刃对 Z0（刀片占 [Z, Z+2.0]）”重写：外圆车至 Z37.200 覆盖槽宽；在 Z35.000 预切至 X14.400；Z34.500 -> G02 X15.000 Z35.000 R0.500 倒大端圆角（刀背全程在预切槽内不伤腰槽）；低进给切断后旋转退至 X38.000 再 M05 停转。

四、若客户确认 M8.0*1.0 为“直螺纹”而非“5度锥螺纹”的快速改法
1. 模块2（T0707 P110-Q190 段）：
   - 只需修改 P110-Q190 一处（G70 自动同步精车）：将前端倒角与锥段 `G01 X6.200;` / `G01 X8.171 Z0.985;` / `G01 X9.820 Z10.410;` 改为 `G01 X6.200;` / `G01 X8.000 Z0.900;` / `G01 X8.000 Z10.410;`，并向设计确认 Z10.410 处是否保留直台阶至 DIA9.82 接 45度斜肩。
2. 模块3（T0606 段）：
   - 删掉 G92 中的 `R-0.962`，保持 `Z9.000`，分刀直径改为 `X7.600 -> X7.300 -> X7.050 -> X6.880 -> X6.760 -> X6.700 -> X6.700`。

五、塑料棒首件试切提醒
- 干切排屑：程序已全面采用干切（无 M08），塑料棒车削、铣槽和切断时注意观察缠屑与融屑情况，必要时人工或按本机气吹代码配合吹屑。
- 刀尖补正确认：确认机床 T07 刀补表 `R=0.000`（不开刀尖半径补正，按理想刀尖对刀）。
- 螺纹刀对刀与退尾微调：T0606 对 Z0 须按 60度刀尖中心对刀（若误按刀片前侧刃对刀会导致实际牙尾整体再向 +Z 偏移约 1~1.5 mm）；已移除未核实的 M34/M35。若试切确认 Z9.000 仍有余量或仍有蹭肩，可按 0.2 mm 步进微调 Z（如 Z8.800/R-0.945/X8.240 或 Z9.200/R-0.980/X8.310，按 `R = -(Z+2) * tan5度` 同步重算）。
- 刀号与对刀核对：首件开单段模式（Single Block）重点核对 `G300 Z____`（须先填入实核数值）、`G150 Z9.900`（实机刀柄非 10mm 时须按 `刀柄宽度 - 0.1` 修改）与 `T0101` 实测落刀距。
- 落料防磕伤：本程序无副轴接料，请在接料槽/集料篮内垫软胶或海绵，防止切断落料磕伤 M8.0*1.0 塑料外螺纹。
- 试切微调：腰槽实测若浅 0.05 mm，在 T01 X 磨耗输入 `-0.100`（直径编程需乘 2）；连续生产时再关闭 `/M92` 跳段并确认送料闭环，将程序尾 `M30` 改为 `M99`（或按本机送料习惯调整）。
