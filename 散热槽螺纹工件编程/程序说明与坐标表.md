# S205A塑料练习件：主轴、重复切槽和副轴程序

本稿根据用户确认编写：津上S205A；图2模板在本机用过；总长35；四槽均宽2.5、三中间凸台均宽2.5；R0.5共9处；M10采用内螺纹车刀；底孔全直径深10；允许采用φ18塑料棒、1.5mm槽刀、2mm切断刀及教学刀号和切削参数。右端C0.5及两段45°斜面也已获得用户确认。

配图：同目录《工件坐标与夹持方案.png》和《底孔深度A方案.png》。全部尺寸以mm计算，假设本机已处于公制输入状态；本稿开头明确G40/G80/G00，取消刀尖R补偿、开孔固定循环及继承的组01运动模态。

**交付状态：名义刀路教学稿，含尚待填写的现场位置。不是已验证的上机文件。** 文件扩展名特意采用`.nc.txt`。下文区分几何计算、教学刀具假设与现场待定项；不能只删除文件名中的`.txt`就上机。

## 1. 三个程序及执行顺序

| 文件 | 存储通道/用途 |
|---|---|
| `O0001_主轴_教学待填.nc.txt` | 主轴通道：模板开头→端面/外形→M6→调用四次切槽→同步接料切断→等本件背面加工及排出→模板尾段 |
| `O0100_重复切槽_刀尖R0.1教学.nc.txt` | 主轴通道子程序：两列单列G75粗切，再精修宽2.5、底φ12、两槽口R0.5的槽，返回原Z；主轴每次移动5mm后再次调用 |
| `O0002_副轴_教学待填.nc.txt` | 副轴通道：接料→等切断及同步解除→带件退回→修背面→钻孔→孔口倒角→M10内螺纹→排出 |

图2中副轴开头的`GOTO99`已取消：本稿把背面加工放在**本件接料切断之后**，并新增两通道`M506`会合。因此每轮都完成本件背面和排出再结束，不依赖“下一轮处理上一件”的首末件分支。代价是没有利用主副轴并行加工缩短节拍。

计算链：

```text
小凸台端面Z = 11.4 − 1.13 = 10.27
φ6.77→φ4的45°斜面轴向长度 = (6.77−4)/2 = 1.385
φ4平直段：Z8.885→Z6.885，长度2.0
φ4→φ6的45°斜面轴向长度 = (6−4)/2 = 1.0
因此φ6外圆近颈端Z = 5.885
大身长 = 35−11.4 = 23.6
右侧大凸台宽 = 23.6−18.6 = 5.0
```

R0.5的9处按“八个槽口凸圆角＋φ13小凸台前外缘一处”分配。这是对总数和图形的几何解释，不把圆角数等同于任意九个角。

粗/精外圆准备到Z37.3，包含完整切断刀宽。2mm切断刀以**高Z侧刃角**为参考，刀宽向−Z延伸：刀具参考Z37.2时，刀片占据Z35.2～37.2，零件粗背面在35.2，副轴去除0.2后总长35。若现场切断刀采用低Z侧刃角为基准，不能照抄37.2，须连同坐标建立一起换算。

副轴：成品背端面为Z2=0，孔内为负Z2。粗背面位于Z2=+0.2。各背面刀具补正都必须对应这个成品面；不能把粗面随意清零，否则总长增加0.2。副轴的接料同轴刀位坐标与T31～T34的加工坐标由真实刀具补正关联，不能用一个零件尺寸替代。

## 4. 重复槽：为什么程序R0.6能得到槽口R0.5

对任一槽，低Z侧名义壁为A，高Z侧为B=A+2.5。T07刀宽1.5，两刀尖R0.1，参考点为低Z侧刀尖两直线刃的理论交点。维持G40，不再叠加G41/G42。

按本次修改，粗切改为**两列单列G75**，槽口和槽底仍用原来的G01/G02精修。每一列均写完整的双行式循环：

```gcode
G75 R0.1
G75 X12.2 P300 R0 F0.025
G00 X18.0
```

采用公制、参考轴增量系统IS-B、P整数单位0.001mm的教学假设：`P300`为每啄径向0.3mm，第一行`R0.1`为径向小回退0.1mm，第二行`R0`令槽底附加侧向让刀为零。X为直径，故啄切最深X值通常逐次减少0.6；小回退时X读数增加0.2。F0.025为每转进给，P和R数值均属教学切削条件，不是塑料通用推荐值。

每个G75均**省略Z/W与Q**，只在当前Z上径向啄切；在X18退出后，显式用W0.8换到槽内第二列。本版把槽内换列0.8和槽间重复5.0分开写，不在G75里跨越四槽。每列从X18到X12.2的径向总行程是2.9mm，按0.3mm分成10次，末次0.2mm；起点至φ16之间的1mm空气间隙也包含在这2.9mm中，不能把10次都解释为切入新材料。

G75循环不使用G41/G42，第一行回退量具有保持性，并会改变相应回退量参数的存储状态；两列都明确重写R0.1。实际控制器的双行格式、P增量单位和循环动作尚需按本机确切版本核对，不因更换为G75就视为已通过控制器验证。

| 步骤 | 参考点Z | 参考点X | 几何意义 |
|---|---:|---:|---|
| 子程序入口 | A | 18 | 刀在外圆之外 |
| 第一列G75粗切 | A+0.1 | 12.2 | 在该Z径向啄切，两侧与底部保留余量 |
| 第二列G75粗切 | A+0.9 | 12.2 | 径向退出后换列，与前列重叠0.7，粗切实际边界A+0.1～B−0.1 |
| 低Z槽口起点 | A−0.6 | 16 | 把刀尖R0.1计入切点偏移 |
| 低Z槽口圆弧终点 | A | 14.8 | 参考点轨迹R0.6，成品凸圆角R0.5 |
| 底部精加工 | A→A+1.0 | 12 | 另一个刃角随刀宽控制高Z壁 |
| 高Z槽口圆弧起点 | A+1.0 | 14.8 | 高Z侧刃角控制B壁 |
| 高Z槽口圆弧终点 | A+1.6 | 16 | 另一端刀尖R同样已经计入 |
| 子程序返回 | A | 18 | 没有在子程序内部累加槽距 |

凸圆角的刀尖圆心轨迹半径是0.5+0.1=0.6；换算到所选虚拟尖角参考点后，低槽口切点为X16→X14.8，而不是把成品轮廓X16→X15直接给这把圆鼻刀。两个角分别使用刀片两端的圆鼻，不能只对其中一侧补偿。

子程序全部W增量相加：0.1+0.8−1.5+0.6+1.0+0.6−1.6=0，故每次返回同一Z。主程序只在前三次调用后移动W5，第四次之后不再多走一个槽距。四次入口A依次为16.4、21.4、26.4、31.4。

**槽底与竖壁连接处会自然留下R0.1。图纸未给出该内角的允许圆角，不能把这点宣称为已获图纸认可。** 若要求更小圆角或清根，应另定刀片及清根段；不能靠把程序R地址改成0来消除刀尖实体圆角。

## 5. M6与M10螺纹

M6采用G92，F1.0不变，各刀X递减；终点Z7.2位于φ4颈槽内，越过外圆斜面上的自然退尾区域，M35关闭G92自动倒角。主轴转向、刀具刃向及正Z切削须成套核对。

M10采用副轴M104、负Z进孔的右旋螺纹教学配置，G92各刀X增大，F1.25不变；刀内回退直径X8.0。S300时名义同步进给为375mm/min，不能把F1.25改小来降低负荷，否则会改变导程。该方向参考手册背面右旋螺纹例，不等于任意反装刀均可照用。

M6末刀X4.77及M10末刀X10.00均为**名义教学试切值**。真实刀片是全牙型还是部分牙型、刀尖半径、几何基准及牙型公差都会改变最终指令/补正，必须按匹配刀具和量规核定。这里没有声称已保证6g/6H、中径或配合精度，也没有把厂家原例的M6末刀X4.60照搬过来。

M10底孔按用户选择的A方案：φ8.8全直径孔深10。118°钻尖高度：

```text
h = (8.8/2) / tan(118°/2) = 2.643787mm
钻尖最终深度 = 10 + h ≈ 12.644mm
```

程序以钻尖Z2=−12.644为最终目标，得到理论全径深约10.0002。刀尖角或钻头形式改变时必须重算，不能把−12.644套给平底钻或其他顶角。

内螺纹刀切削终点取Z2=−8.0，较全径孔底留2mm，且工具整个前端均需在该余量内让开。孔口取φ10.6，经45°到φ8.8、深0.9。这些属于教学工艺选择。**切到8mm不等于具有8mm完整有效牙长**：入口倒角、同步加减速和刀片本身都会占用牙长。若有实际有效牙长要求，需另外给定并重新核查孔底余量。

## 6. 副轴夹持评估

建议用匹配本机副轴接口的φ16软夹头/专用夹头，在右端宽5mm大凸台的**Z1=11.9～15.7**区域夹持，轴向有效夹持带约3.8mm。该处未被M10底孔削弱；夹头内部让开M6、φ4颈部及φ13小凸台，不用这些小径定位夹紧。

- 大凸台直圆柱范围为Z11.7～15.9，两端分别被C0.3和槽口R0.5占用。夹持带两端各让0.2mm。
- 夹头口端拟在Z1=15.7，成品背面从夹头口伸出35−15.7=19.3mm；粗背面伸出19.5mm。
- 从M6前端至夹头口的进入长度为15.7mm，夹头内部净深、顶料销和过孔必须能够容纳，不能只看φ16夹持孔径。
- 内螺纹所在外槽φ12处，φ10名义牙底外的单边壁厚约1mm，故选择前方实心大凸台承夹，而不夹这些薄壁区。

这是几何上可行的候选方案，不是已验证的夹具设计。3.8mm夹持长度较短，必须核对夹头实际接触、塑料压缩/回弹、轴向定位重复性和切削时抗滑移，夹紧力不由本图推定。若标准夹头不能稳定夹住该带，应使用经确认的专用夹头或修改工艺，不能靠盲目加紧处理。
