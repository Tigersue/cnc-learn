# 津上S205A/S206A｜手册总导航

以用户问题为入口，按本模块流程查证原文，再给可追溯的解释或核查步骤。

## 使用范围与证据

- 以本技能自带的3281-LTQ0C-05中文手册原页为依据；适用名称为津上TSUGAMI S205A/S206A。全局可调用只表示跨对话使用，不表示适用于任意机床。不要默认适用于SS207。
- 封面标注FANUC 0iTF Plus、27610B～、23.04；上传文件名为机号3001～，前言又提0i-TD。存在适用性冲突。概念学习可先说明适用假设；实际按钮、参数、接线或程序执行前核对机台铭牌、控制器和选配。不要反复询问已明确的信息。
- 优先查本文的主题路由及[原文索引](references/index.md)。[文字层原文](references/manual-text.md)是机械提取，图、表、小数点、±号、通道并列程序及扫描页必须对照[原页节选PDF](assets/manual-excerpt.pdf)。
- 不凭旧目录给页码：本手册有目录与正文错位、扫描页和内部规格冲突。用[来源与页序映射](references/source.json)同时核对原PDF页序、纸面页码、节选页序；所有脚本命令接受的是**原PDF页序，从1开始**。
- 回答时区分“手册明示”“根据已知条件计算/推导”“尚未确认”。具体代码、参数、尺寸、顺序、周期均先读对应原页；没有依据就写未查到，不补成厂家规定。
- 来源写成“§章节，纸面页码（原PDF第N页）”；纸面页码不可辨认时只引用原PDF页序。不要把当前节选页序或临时路径冒充原始页码。

## 检索与看图

脚本[manual.py](scripts/manual.py)按自身位置查找资源，可从任何工作目录调用。先取得本技能实际根目录，将其记为shell变量`skill_dir`；使用带引号的脚本路径。无需原上传文件、Library连接或网络。

```bash
python "$skill_dir/scripts/manual.py" search "关键词" --limit 8
python "$skill_dir/scripts/manual.py" search "关键词1|关键词2" --regex --limit 8
python "$skill_dir/scripts/manual.py" show 原PDF页号
python "$skill_dir/scripts/manual.py" render 原PDF页号 --out /tmp/s20a-page.png --dpi 180
python "$skill_dir/scripts/manual.py" render 原PDF页号 --out /tmp/s20a-detail.png --dpi 300 --clip 0.0 0.65 1.0 1.0
```

- 将命令里的“关键词/原PDF页号”替换为实际内容。`show`返回整页文字；`render`从内附PDF渲染原页后，必须用图片查看工具看图，不能仅凭“渲染成功”作结论。
- 查不到词不等于手册没写；扫描图页按索引定位。需要放大时先看整页再裁剪，clip坐标为页面宽高的0–1比例。
- 若无法执行脚本，读取本技能资源中的索引和文字；必须看图的任务无法查看PDF时，明确证据不足，保留判断，不臆读。

## 操作与回答约束

- 先回答用户实际问题，用简明中文解释概念，保留面板英文与原代码。教学优先“它是什么→作用→对应原图/例子→怎样核对”，不一次倾倒全模块。
- 对机械操作明确对象、通道/轴、模式、夹持、停止/供电/气源状态与完成判据；只补问会改变结论的缺失项。安全要求结合具体原文，不堆叠无关警告。
- 严格保留任务特有的电源条件。不要用“所有维护必须断电”覆盖§6.17电池更换NC ON的特例；其他维修也不能因该特例被允许带电。电控维护按手册资格要求处理。
- 不绕过门锁、急停、送料或干涉保护；不为消除报警而盲改参数。实际参数变更应保留原值、来源、验证及写保护恢复条件。
- 手册例程用于讲解；缺少真实刀具、工件、补正、坐标、选配和验证时，不声明程序可直接上机。保持用户原程序不被静默改写。
- 用原图或精确矢量/绘图辅助几何、坐标、刀路解释；标注假设与观察方向。不要用生成式图片画必须精确的机床坐标或电气接线。

## 本模块处理流程

1. 先把请求分为概念学习、画面/操作、程序解读、机械调整、维护、报警、电气图或选配确认；根据下面的模块表选择最贴近的技能。
2. 用户只说“继续/下一步”时，使用可见对话的学习进度；没有进度就从安全、部件与坐标开始。不要把记忆中的机型视为当前机台的确认结果。
3. 针对一个明确问题直接定位章节；不要先强制讲完整本手册。用户要求系统学习时，按安全与规格→基本操作→装刀与坐标补正→基础指令与双通道→试切量测→维护与排障安排。
4. 用本技能的模块表与覆盖索引查到模块后，读取该模块 SKILL.md 及其原文。跨模块问题按需要读取；各专题技能自带原文，不依赖本总导航的临时文件。
5. 找不到指定技能时，在实际技能根目录的各 SKILL.md 中按 frontmatter 的 name 精确查找；安装后目录可能改名为 skill-标识，不能假定目录名等于调用名。不要声称已调用不存在的技能。总导航的原文仅含前置资料，不能用目录条目替代正文证据。
6. 每次教学先解释一个核心概念，再用表格或精确示意图说明，最后给一个简短练习。询问机台实际参数的时机只限于它确实改变结论时。

## 关键分界与易错点

- 原目录已过时：第2章、7.6以后等页码与正文不一致；优先使用本技能的实际页序覆盖表。
- 将纸面页码与原PDF物理页序同时给出；不能将节选PDF的第几页当作原PDF页序。
- 原PDF第443–484页为42页扫描接线图；第485页为PMC标题资料，不是完整梯形图。
- 用户要逐行解释实际程序时，请取得程序原文并切换编程/双通道模块；不要虚构用户已有模板。
