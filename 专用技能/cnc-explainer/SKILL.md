# cnc-explainer（CNC 工序与程序交互式讲解技能）

用于把一段 CNC 程序、一条 G 代码或一道具体工序讲到“**看懂怎么动、算清每个数、知道坑在哪**”。与 `cnc-coach`（识图、工艺、整件编程与审查）配合使用；凡涉及本机规格、用户约定与 18 个津上 S205A/S206A 专项模块时，沿用 [cnc-coach](../cnc-coach/SKILL.md) 的基准、公式与证据边界。

## 适用场景

- 用户说“讲解某某工序 / 这段程序 / 这个循环 / 极坐标 / G75 / G92 怎么走”或希望“一步步看懂刀和工件怎么配合”。
- 一次聚焦**一道工序或一个动作块**，不把整份长程序一次性铺满屏幕。

## 五步讲解流程

按以下 5 个模块组织回复，缺一不可（极简概念题可省略双表，但只要涉及具体刀路和坐标，必须给齐点号、双表与交互动图）：

### 第 1 步：白话破题（程序视角 vs 机床真实动作）

- 先用 2–4 句话交代**为什么要用这种加工方法**，以及**系统替操作员干了什么**。
- 明确区分**编程坐标系里写的坐标**（如 X 直径值、虚拟直线轴 C、刀具相对工件路径）与**机床物理轴实际运动**（如刀架只在 X2 滑、副轴带工件旋转、走心机主轴 Z1 带着棒料伸缩）。

### 第 2 步：内联交互式精确动图（核心）

调用 `generative_ui` 规范，在当前对话的 Artifact 目录生成自包含的 HTML/SVG 交互动图并用 `<agent-embed>` 嵌在回复中。详细制作规范、各工序双视角选型及 SVG 几何防错公式见 [交互动图制作规范](./references/visual-widget-spec.md)。

动图必须满足：
1. **1:1 真实几何计算驱动**：所有轮廓、刀径、圆弧与转角全部由真实坐标公式算出，禁止手画示意或生成式图片。
2. **双视角同步**：左侧展示**编程视角**（工件固定、刀心沿程序轨迹走），右侧展示**机床真实动作**或**正交补充视角**（如 X2 直线 + C2 旋转、侧视 Z 分层/切深、槽刀双刃覆盖）。
3. **逐段可控**：提供播放/暂停、上一段/下一段及每段点号按钮（如 `P0→P1`），点击即可定格观察。
4. **实时遥测读数**：底部同步显示当前段号、对应 NC 原代码行、程序坐标、实体坐标/半径，以及本工序最关键的物理指标（如近心 C 轴瞬时角速度、内弧刃口折算进给、残余壁厚、槽刀另一刃 Z 位）。
5. **紧凑免滚动**：总高度控制在 `<= 420px`，使用语义 CSS 变量兼容深浅色主题。

### 第 3 步：尺寸到刀位的透明换算

按“图纸/原文明示 → 基准与刀具 → 刀位计算 → 覆盖/干涉检查”交代每个关键数字的来历：
- 写清当前通道（主轴/副轴）、`Z0` 位置、入料正负方向、X 直径/半径制、刀具尺寸与参考点（刀心/刀尖/某侧刃角）、是否保持 `G40`。
- 明确写出偏置与特征公式（如腰孔向内偏、腰台向外偏、半圆拆两段 90° 左右最外点各一行；槽刀算参考刃与另一刃；60° 螺纹用用户确认公式）。
- 补一条几何自检（如两直边刀心距 < 刀径确保不留岛、槽宽覆盖无残留、最小壁厚或净空足够）。

### 第 4 步：共用点号的绝对/增量双表与闭环反算

图、表、代码**严格共用同一套点号**（`P0, P1, P2…`），让用户可以直接报“P3 怎么来的？”定位：

1. **表 1（绝对点位表）**：列 `点号｜位置或动作｜实体坐标｜程序坐标｜数字来源`。X 为直径编程时，必须同时给出实体半径 `r = X ÷ 2` 与程序直径 `X`。
2. **表 2（走刀顺序与带符号增量表）**：列 `走刀段｜ΔX(直径差)｜实体Δx｜ΔZ 或 ΔC｜对应程序行`。按 `增量 = 终点 − 该段实际起点` 计算。
3. **闭环反算**：在表后用一行算式把各段增量从起点累加回终点，验证坐标零漂移；若程序本身用绝对坐标（如 `G12.1` 内），说明原因并仍保留增量核对表。

### 第 5 步：核心代码分块拆解与 3 个最硬核易错点

- **只贴当前工序直接相关的代码**，有原文件时附可点击路径与行号范围。代码块前标明**入口状态**（刀具、当前 Z/X、模态、主轴/动力头状态）与代码性质（教学片段/审查稿，非已验证量产程序）。
- 将代码拆成 3–4 个小块讲解：**① 入口与模式开启 → ② 单层/单循环完整动作 → ③ 分层/重复接续规律 → ④ 安全退刀与模式退出**。
- 总结 **2–3 个最关键的物理或实机易错点**，优先讲清“为什么”：
  - **进给与速度的物理原因**：写出具体算式（如内弧刃口折算倍数 `R_孔壁 ÷ R_刀心`、极坐标过中心附近 C 轴角速度 $\omega = \frac{F}{r} \times \frac{180}{\pi}$、主轴恒线速与每转/每分钟进给区别）。
  - **切入与刀具边界**：明确当前写法的工艺前提（如中心直插要求过中心刃、材料为试切假设）及换材料/换刀时的替代方案（如改斜插、螺旋下刀、分层减深）。
  - **现场核对边界**：区分“已确认的本机条件”（如副轴无 Y2、配极坐标）与“上机前仍须仿真/空运行核对的项”（M 码映射、刀号、单位参数、正方向/镜像、夹紧与干涉），不把几何核算说成“实机已验证”。

## 收尾约定

结尾留一句短互动，让用户可以直接挑一个点追问（报点号/行号），或选择下一道要讲的工序/改法；除非用户要求，不顺手修改原程序文件。

## 检查清单（交付前自检）

- [ ] 动图中的点号、坐标、圆弧方向、旋转方向与正文双表、NC 代码完全一致。
- [ ] SVG 坐标系（y 向下）转换到物理坐标系（+Y/+C 向上）的符号及圆弧 `sweep-flag` 已验算无镜像错误。
- [ ] 所有重要数值都标明了来源与分类（图纸/原文明示、计算、教学假设、待确认）。
- [ ] 动图高度紧凑（≤ 420px），无外部失效资源，深浅色主题均清晰可读。
