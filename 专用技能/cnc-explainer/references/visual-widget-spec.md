# 交互动图制作规范（CNC 讲解专用）

配合 [SKILL.md](../SKILL.md) 第 2 步使用。生成内联交互动图前，先同时遵守系统内置 `generative_ui` 技能的约束。

## 1. 交付方式与布局约束

- **文件位置**：直接用原生文件创建工具写到当前对话的 Artifact 目录（`<Artifact Directory Path>/<topic>_walkthrough.html`），并填写 `ArtifactMetadata`（`UserFacing: true`, `RequestFeedback: false`）。
- **内联嵌入**：在聊天回复的对应位置插入 `<agent-embed src="file:///<Artifact Directory Path>/<topic>_walkthrough.html"></agent-embed>`。
- **尺寸预算**：内联组件目标高度 **`360px – 420px`**（绝不超过 450px），避免出现滚动条；禁止对顶层容器使用 `h-screen`、`100vh`、`height: 100%`。
- **样式与主题**：
  - 仅允许引用 `https://www.gstatic.com/antigravity/web/dev/tailwindcss.min.js`，禁止加载任何其他外部 CDN。
  - `<body class="bg-transparent text-[var(--foreground)] antialiased p-0 m-0">`，不套多余的外层大卡片。
  - 所有颜色必须使用注入的语义变量：`--foreground`、`--muted-foreground`、`--card`、`--card-border`、`--border`、`--background`、`--content`、`--primary`、`--primary-foreground`、`--secondary`、`--accent`、`--code-foreground`、`--chart-1`..`--chart-6`、`--warning`、`--error`、`--success`。禁止写死黑底/白底色值。

## 2. 推荐三段式骨架（约 370px 高）

1. **顶部控制栏（~34px）**：`暂停/播放`、`上一段`、`下一段` 按钮 + 各走刀段快捷按钮（`P0→P1`、`P1→P2`…，当前段高亮）。
2. **中部双 SVG 画布（~245px，`grid-cols-2 gap-3`，每张 SVG 高 `210px–220px`）**：左右并排同步，标清标题、坐标方向与图例。
3. **底部实时遥测栏（~64px）**：
   - 第 1 行：当前段号徽章 + 高亮 NC 代码原文 + 一句白话动作说明。
   - 第 2 行：4 格等宽数值卡片（`font-mono tabular-nums`），按工序展示关键实时参数；触及物理警戒值（如 C 轴转速 > 2000 °/min、切深超限等）用 `var(--warning)` 高亮。

## 3. 各 CNC 工序的双视角选型

| 工序类型 | 左画布（编程 / 轮廓视角） | 右画布（机床真实动作 / 补充视角） | 底部 4 项推荐读数 |
|---|---|---|---|
| **极坐标插补（`G12.1`）** | 虚拟 `X–C` 直角平面（成品槽 + 刀心轨迹 + `P0–Pn`） | 机床真实运动（刀只沿 `+X2` 滑动 + 工件绕 `C2` 旋转） | 程序 `X/C`｜刀心距中心 `r`｜`C2` 转角｜`C2` 瞬时转速 `°/min` |
| **圆柱插补（`G07.1`）** | 展开平面（`Z` vs 展开弧长/角度 `C`） | 端面/侧视真实圆柱（刀沿 `Z` 走 + 工件绕 `C` 转） | 程序 `Z/C`｜展开位移｜`C` 转角｜当前合成进给 |
| **端面/侧面分度铣（`G17/G19`）** | 端面/侧面成品轮廓与刀心轨迹 | 分度后工件姿态与相邻刀/夹头包络净空 | 程序 `X/Y/Z`｜实体偏心/弦长｜`C` 分度角｜刀刃折算进给 |
| **外圆/内孔车削（`G71/G90/G01–03`）** | `(Z, r)` 实体比例剖面（毛坯、已去除区、精车轮廓） | 局部放大（刀尖 R 轨迹 / 倒角 / 相切圆弧过渡） | 程序 `X(直径)/Z`｜单边切深｜累计增量 `U/W`｜当前模态 |
| **切槽与啄切（`G74/G75`）** | 槽剖面 + **双刃槽刀实体**（同时画参考刃与另一刃） | 当前啄切列位与让刀/退刀时序 | 参考刃 `X/Z`｜另一刃实际位｜当前列覆盖｜剩余余量 |
| **车螺纹（`G92/G76/G32`）** | 轴向多刀进退循环（同步引入、切牙、退尾、回起点） | 牙型截面逐刀加深（大径、中径、小径与径向切深） | 刀次｜当前 `X`｜本刀单边切深｜距目标小径余量 |
| **刚性攻丝（`G84/G184–186`）** | 钻尖底孔深度、有效牙长与丝锥导入牙相对位置 | 主轴/动力头旋向与 Z/X/Y 同步进退状态 | 当前深度｜有效牙长余量｜旋向/同步态｜孔底延时 |

## 4. SVG 几何与符号防错清单（必核）

SVG 屏幕坐标系中 **`+X` 向右、`+Y` 向下**，而机械图纸端面视图通常 **`+X` 向右、`+Y/+C` 向上**。写脚本前必须逐项验算：

1. **坐标映射**：统一封装 `S(x, y) => [x, -y]`。所有实物坐标用物理单位（mm）直接放入 `viewBox`，保证 **1:1 等比例**，视觉不畸变。
2. **圆弧 `sweep-flag` 检查**：
   - 在 SVG（y 向下）坐标系中，**视觉逆时针（对应物理平面 `G03`）的 `sweep-flag` 为 `0`**；
   - **视觉顺时针（对应物理平面 `G02`）的 `sweep-flag` 为 `1`**。
   - 写完每条 `<path>` 后，用终点代入参数方程 `(cx + R cos α, cy + R sin α)` 核对起终点连续。
3. **极坐标旋转矩阵校验**：
   - 设物理坐标系中刀心位于 `(x, c)`，极径 $r = \sqrt{x^2 + c^2}$，极角 $\varphi = \mathrm{atan2}(c, x)$。
   - 在 SVG 中该点位于 `(x, -c)`。为让该点随工件转到固定 `+X2` 导轨上的 `(r, 0)`，对工件 `<g>` 施加 `transform="rotate(φ_deg)"`（SVG 顺时针转 `φ`）：
     - $u' = x\cos\varphi - (-c)\sin\varphi = \frac{x^2+c^2}{r} = +r$
     - $v' = x\sin\varphi + (-c)\cos\varphi = \frac{xc - cx}{r} = 0$
   - 刀 `<g>` 仅做 `transform="translate(r, 0)"`。
4. **瞬时角速度公式**：
   - 已知刀心线速度向量 $(v_x, v_c)$（单位 mm/min），则 `C` 轴瞬时角速度（单位 `°/min`）：
     $$\omega = \left|\frac{x \cdot v_c - c \cdot v_x}{r^2}\right| \times \frac{180}{\pi}$$
   - 在程序直线经过中心附近（$x = 0, c = \pm r_{\min}$）处检验是否等于 $\frac{F}{r_{\min}} \times \frac{180}{\pi}$。
5. **点号防遮挡**：点号标签（`P0`–`Pn`）应沿法向或远离轮廓线错开摆放，字号在 `viewBox` 折算后清晰可读，不压住线条和中心标。
