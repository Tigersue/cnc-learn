# G74 端面切槽循环：格式、啄切与环槽尺寸计算

本资料结合学习目录中的津上 TSUGAMI S205A/S206A（3281-LTQ0C-05）及 FANUC 车床双行式格式。津上 §7.5，纸面7-25（原PDF第293页）将 G74 列为“端面切断循环”，主轴侧、副轴侧均有列出；其完整地址格式用 FANUC 原厂控制器手册补充，不把自拟程序称为津上原例。

已补充 [手册原图与实例对照](G74手册原图与实例对照.md)：包含FANUC的G74原格式/刀路图、津上正面断屑钻孔原例及逐行对照，并辨析深孔、T铣刀割槽与同步切槽实例。[原图与讲解合订PDF](../output/pdf/G74_手册原图与实例对照.pdf) 保留原页供核查。津上已核查的§7.9-7.10中未找到G74原程序；下文环槽尺寸仍是自拟教学例。

概念学习采用：公制、G18/ZX平面、X直径编程、代码制A、参考轴IS-B增量系统、G99每转进给，未启用G41/G42。P/Q一个整数单位假设为0.001 mm。沿津上 §7.3，纸面7-6（原PDF第274页）程序坐标图，工件右端面为Z0，+Z向左入料，+X离开中心线。图示为刀具相对工件；走心机实际轴运动不能简单理解为刀架沿Z移动。未核现场控制器、选配和坐标前，示例仅用于纸面学习。

## 1. 作用与方向

G74主要沿Z分次深入，在每次深入后小退刀，直到到达指定深度。需要扩大端面环槽的径向宽度时，再沿X换列，重复Z向啄切。

- 端面单列切槽：固定X，仅沿Z啄切；名义径向槽宽取决于刀刃有效宽度。
- 端面宽环槽：沿Z切到底、轴向退出、沿X换列，再沿Z切削。
- 中心啄钻：把钻头对中到X0，省略循环行的X/U及P，仅做Z向啄钻。实际孔深还需区分钻尖位置和完整孔径深度。

G74与G75中，P仍对应X方向，Q仍对应Z方向；区别在于G74用Q控制Z向每啄量，G75用P控制X向每啄量。不能把它们记成“P、Q地址交换”。

## 2. 双行式格式

```text
G74 R(e);
G74 X(U)_ Z(W)_ P(Δi) Q(Δk) R(Δd) F(f);
```

括号内是说明符号，不是要原样输入的内容。X/U、Z/W分别选绝对终点或增量表达；以下按代码制A解释。

| 地址 | 含义 | 本文条件下的读法 |
|---|---|---|
| 首行R(e) | 每次Z啄切后的轴向小回退量 | R0.2为轴向退0.2 mm |
| 第二行X | 最后一列刀具参考点的X终点 | X13.0表示参考点位于半径6.5 mm |
| 第二行U | 从循环起点到最后参考点的X增量 | X16到X13写U-3.0，是直径差 |
| 第二行Z | Z切入终点 | 本例Z4.0表示参考刃到端面内4 mm |
| 第二行W | 从循环起点到Z终点的增量 | Z-1到Z4写W5.0 |
| P(Δi) | X方向相邻列的径向移位量 | P1000为径向1 mm，对应X直径值变化2 mm |
| Q(Δk) | Z方向每啄的名义新增深入量 | Q1000为轴向1 mm |
| 第二行R(Δd) | 到底后的X方向让刀量 | 本例R0使该附加动作归零 |
| F | 切削进给 | G99下F0.03表示0.03 mm/rev |

FANUC将这些局部切入/回退量按实际长度或半径量处理；不要因为X直径编程，就把P或径向底部让刀也当直径差。

### P/Q的整数单位

本例公制IS-B条件下：

```text
P1000 = 1000×0.001 = 1.0 mm（径向列距）
Q1000 = 1000×0.001 = 1.0 mm（轴向每啄量）
```

所引FANUC格式不允许P/Q输入小数点，不能写成P1.0 Q1.0来表达上面的长度；其他增量系统须按对应手册换算。P/Q给正的量值，前进方向由起点与终点决定。它们既不是G71的轮廓段号，也不是啄切次数或停留时间。

### 两个R分别做什么

第一行R控制Z向断屑小回退；在本例+Z入料时，小回退朝−Z。它有保持性，控制器原文还说明程序指令会更新相应存储值。因此例子显式写出R0.2，不依赖上一程序遗留值；这不需要学习者自行改参数。

带轴地址的G74行中，R表示槽底X向让刀。它不是槽底圆角、精加工余量、Z安全面或总退刀距离。通常给正值，让刀方向结合循环走向核对；当省略X/U及P、只做单列Z啄切时，原厂要求用符号指定非零让刀的X方向。中心钻若无相应工艺目的，不应随意加入径向位移，本教学片段显式R0。

第二行R0不会取消第一行R0.2：Z小回退仍存在，只取消槽底附加X让刀。

控制器格式依据：FANUC B-64694EN-1/01，§4.2.5，纸面64–65；对照B-64604EN-1/01，§4.2.5，纸面78–79（本地PDF第92–93页）。

## 3. 例一：固定X的单列端面切槽

自拟条件：端面Z0，切入终点Z4；循环开始前，刀具参考角已经位于X16、Z−1。名义矩形刀刃径向宽1.5 mm，以切刃的外径侧角为参考，刀刃覆盖半径[X/2−1.5，X/2]。因此参考点X16时，刀刃覆盖半径6.5～8，即端面φ13～φ16环带。

以下仅为循环核心片段。前提是刀具与补正正确、该起点和退出路径已核实、主轴按经过审核的方向/转速旋转且冷却适当。F0.03仅是演示读数，不是材料推荐进给。

```gcode
N10 G18 G99;
N20 G74 R0.2;
N30 G74 Z4.0 Q1000 R0 F0.03;
N40 G00 Z-1.0;
```

| 行 | 含义 |
|---|---|
| N10 | 明确ZX平面和每转进给 |
| N20 | 设每啄后Z小回退0.2 mm；尚未给切入终点 |
| N30 | 不给X/U及P，保持当前X16，仅沿Z啄切到4 |
| N40 | 明确后续G00与指定轴向退出目标；不以此倒推所有版本的循环自动结束位置 |

Q从循环起点Z−1划分行程，控制器不会自动把毛坯端面Z0识别为啄切起算点。相邻最深位置按Q增加，最后不足Q时只走剩余量。

| 啄次 | 最深Z/mm | 非最终啄的小回退后Z/mm | 新增加的材料深度/mm |
|---:|---:|---:|---:|
| 1 | 0.0 | −0.2 | 0，刚到端面 |
| 2 | 1.0 | 0.8 | 1.0 |
| 3 | 2.0 | 1.8 | 1.0 |
| 4 | 3.0 | 2.8 | 1.0 |
| 5 | 4.0 | 到底后轴向退出 | 1.0 |

从Z0回退到−0.2后，下一次工进到Z1，实际工进行程为1.2 mm，其中0.2 mm重走已加工范围，新深入1 mm。不能将1−0.2=0.8 mm当作每啄的新切深，也不能把每次小退刀误画成退到Z−1的完整排屑。

本例轴向总行程=4−(−1)=5 mm；材料内槽深=4 mm。若Q改为Q1200，即1.2 mm，最深位置为Z0.2、1.4、2.6、3.8、4.0，末次名义新增深入0.2 mm。这是行程计算，不是推荐啄切量。

## 4. 例二：同一把刀扩成φ10～φ16的宽环槽

目标端面环槽外径φ16、内径φ10、轴向槽深4 mm；径向总槽宽：

```text
径向槽宽 = (槽外径−槽内径)/2 = (16−10)/2 = 3 mm
```

刀宽1.5 mm仍采用外径侧参考角，沿−X从外向内排刀。首列参考X16，刀覆盖φ13～φ16；要使末列内侧刃到φ10，末列外径侧参考角应为：

```text
末列参考X = 目标槽内径 + 2×刀宽
           = 10 + 2×1.5 = 13 mm
参考点径向总移位 = (16−13)/2 = 1.5 mm
成槽径向总宽 = 参考点径向总移位 + 刀宽
             = 1.5 + 1.5 = 3 mm
```

这些式子以本例参考角、向内排刀方向和矩形有效刀刃为前提；若用内侧刃角或中心对刀，须重新推导。

```gcode
N10 G18 G99;
N20 G74 R0.2;
N30 G74 X13.0 Z4.0 P1000 Q1000 R0 F0.03;
N40 G00 Z-1.0;
N50 G00 X16.0;
```

起点与前置条件同例一。按所引FANUC原图，路径末端为B，即本例最后X13与起始Z−1的交点；原图未画B返回最初A。N40再次明确轴向目标，N50才把径向参考点返回X16；现场仍须按确切控制器版本核对结束位置。

P1000为径向列距1 mm；X直径值的整步变化是2 mm。列位及覆盖为：

| 列次 | 外径侧参考X/mm | 刀刃半径覆盖/mm | 等价直径范围/mm |
|---:|---:|---|---|
| 1 | 16 | 6.5～8.0 | φ13～φ16 |
| 2 | 14 | 5.5～7.0 | φ11～φ14 |
| 3 | 13 | 5.0～6.5 | φ10～φ13 |

最后一步参考点只需径向再移0.5 mm，X由14到13；不会强行再走完整1 mm到X12。总共3列；一般顺序是到底、按第二行R让刀、轴向退出，再换X。本例第二行R0，故没有槽底附加X让刀。不能理解成停在Z4槽底横向拖刀把环槽挖宽。

若误将终点写X10，刀具外径侧角会走到φ10，内侧刃将到φ7，名义环槽被扩成φ7～φ16。本例的目标内径φ10不能直接照抄为X终点。

在本例向内排刀及有效刀宽假设下，连续清除环带需使径向列距p不大于有效径向刀宽b，避免留肋。这只保证名义几何覆盖；刀片圆角、面槽刀允许的最小/最大加工直径、刀杆曲率、悬伸与负荷仍需核对。不是任意外圆切槽刀都能沿Z加工这样的环槽。

当循环起点严格为X16、Z−1，代码制A的增量写法可对应为：

```gcode
G74 U-3.0 W5.0 P1000 Q1000 R0 F0.03;
```

U−3是直径差，不是径向移位−1.5；W5是从起点到终点的位移，不是材料内深度4。

## 5. 中心啄钻怎样用

若当前钻头已经正确对中在X0，循环起点Z−1，需要将钻尖参考点送至Z10，可用相同的单列形式理解：

```gcode
G18 G99;
G74 R0.2;
G74 Z10.0 Q2000 R0 F0.03;
G00 Z-1.0;
```

此处Q2000在本文增量假设下为Z向2 mm；最深位置为Z1、3、5、7、9、10。X/U与P省略不代表自动到X0，必须在循环前完成对中。钻孔直径由钻头决定，也不是用循环终点X来指定。

示例中的10 mm是钻尖参考点位置，不自动等于具有完整孔径的孔深；还要考虑钻尖角、刃长、通孔穿出、底部余厚、冷却与排屑。G74的小退刀也不自动等同于每啄都退到孔外的深孔排屑工艺。

## 6. 选用数值与常见误解

| 项目 | 按什么决定 |
|---|---|
| Z终点 | 目标轴向深度与刀具轴向参考点 |
| X终点 | 环槽内外径、径向刀宽、刀具参考角、排刀方向 |
| Q | 材料、刀具断屑条件、槽深、冷却与负荷 |
| P | 径向刀刃有效宽度和重叠量；连续环槽与分离环槽目标不同 |
| 首行R | 需要的断屑小退让；过大会增加往返距离 |
| 第二行R | 槽底X让刀方向与空间，不能随意沿用其他程序 |
| F与转速 | 当前进给模式、材料与刀具数据、夹持及设备限值 |

G74不提供本例意义上的自动精加工余量功能；第二行R不是余量。若需要粗、精分开，应分别推导粗加工参考点和精加工路线。所引控制器明确不能应用刀尖圆弧半径补偿；刀具几何/磨耗补正与G41/G42是不同事项。

G74列在组00，不能仿照模态G90循环，在下一行只写一个Z就期待再做一次G74。重做时明确G74及起点。也不需要仅为结束本次G74而照搬开孔固定循环的G80。图解中的播放或暂停是学习交互，不代表实机单段会在每个内部啄切动作结束时停下。

G99下主轴停止时不能执行每转进给；津上§7.5.9纸面7-45（原PDF313）对此有明确说明。实际F、转速与啄切量尚未由材料和刀具条件确定，本资料所有数值只用于读程序与几何计算。
