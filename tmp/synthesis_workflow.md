## 总手册建议采用的纵向主线

“图纸要求 → 基准和坐标 → 工序安排 → 刀具参考点 → 指令动作 → 模态和通道状态 → 测量反馈”。每个学习主题都回答七个问题，避免只背G码名。

1. 图纸要求：加工什么表面，名义尺寸、长度链、孔的通盲与倒角是什么。培训图未指定材料，也未给出可以自行采用的公差，不能把名义值当验收上下限。
2. 基准和坐标：原点在哪里，X是直径还是半径，+Z朝哪里，翻面是否换了基准。图在纸面左右颠倒不会自动改变真实轴正向。
3. 工序安排：先建立端面，保持刚性完成孔，粗车留量，精车外形，再做槽/螺纹，切断，翻面或副轴加工背面。此为训练例顺序，不是所有零件唯一工艺。
4. 刀具参考点：零件边界不总等于程序参考点。槽刀有宽度，钻头有尖角，真实车刀有刀尖R。
5. 指令动作：先画起点、切削段、退让、返回，再代入循环参数；长轮廓和分刀循环用同样思路。
6. 模态和通道状态：同一F要看G98/G99，同一S要看G96/G97，单轴工艺段还依赖夹持、刀位、同步、送料等完整状态。
7. 测量反馈：先量固定基准下的尺寸，再区分位置偏差、形状/斜率偏差、刀宽/钻尖等参考点错误；不要看到偏差便修改不相关补正。

可用四层学习阶梯：第一层“认坐标与动作”；第二层“比较循环和参数”；第三层“用工件串工序”；第四层“读双通道和验证首件”。

### 三种参考点计算放在一张对照表中

| 情况 | 所求量 | 教学例 |
|---|---|---|
| 刀宽 | 最后低Z参考点 = 目标高Z边界 − 刀宽 | 成品槽Z2–7，刀宽2，完成远壁时参考点Z5 |

| 45°外倒角 | 直径变化 = 2×轴向倒角尺寸 | φ12前端C0.4：X11.2/Z0→X12/Z0.4 |
| 翻面 | Z新=30−Z旧，针对本例成品端面基准 | 旧粗切断面Z30.2→新Z−0.2；旧成品Z30→新Z0 |

### 首件测量对应工序

量总长30、肩面Z2/7/11.2/15.8/20.5/25、槽底φ10.60/φ6.62、φ16/φ14/三段φ12、φ3通孔和各倒角。槽底尺寸看径向留量，槽宽与肩面看两刃基准，孔是否贯穿看完整直径而非钻尖，翻面总长看定位长度链。未给公差不自行设合格范围。

## 锥度独立专题

来源：output/pdf/锥度比计算与实际加工_图文学习手册.pdf，11页。以下公式为一般几何，例题D16、d12、L40是自拟教学尺寸。

C=(D−d)/L；1:n中的n=L/(D−d)；d=D−L/n；tanα=(D−d)/(2L)=C/2；α为半角，全角为2α。

本例C=4/40=0.1，即1:10；α=arctan0.05≈2.8624°；全角≈5.7248°。1:10指轴向10，直径变1，不是10°。L是轴向长度，不是斜面长度。

从小端沿+Z向大端：X(Z)=12+0.1Z。Z0/10/20/30/40对应X12/13/14/15/16。X变化4，径向只变2。已在A(X12,Z0)时，G01 X16 Z40形成直锥；先只改X后只改Z会成折线。F影响快慢，端点决定直线斜率。

加工次序：认图及基准 → 安装与对刀 → 分层粗车留量 → 刀尖R补偿后的连续精轮廓 → 固定截面测量。毛坯φ16车至小端φ12，总径向去除量2mm，不是建议单刀切深。刀柄不需斜装到锥面半角；安装、几何中心高、刀尖R补偿要分开。G41/G42选择不能仅按Z正负。

测量对比是该PDF最有价值的独有内容：

| 固定测点Z10/Z30 | 直径差 | 平均锥度 | 解读 |
|---|---:|---:|---|
| 目标13/15 | 2.00 | 0.100 | 1:10 |
| 实测13.04/15.04 | 2.00 | 0.100 | 两端同偏+0.04，先查位置/补正/Z基准 |
| 实测13.04/15.06 | 2.02 | 0.101 | 约1:9.901，先查斜率、定位或变形 |

理想直线模型中，统一X补正平移轮廓，不改变两截面直径差；不能用同一磨耗值消除斜率误差。固定截面处|ΔD|=C×|ΔZ|，本例Z基准错0.1可表现为直径错0.01。两个测点只给平均锥度，需中间测点辅助看轮廓弯曲，不能证明全长直线度或接触合格。

可纳入记忆句：“锥度看直径，角度看半径；先定截面，再量直径；同偏查位置，差偏查斜率。”最后一句仅为排查入口，不是唯一故障判据。

## 自动模板学习要点

来源：自动加工模板_逐段详解.md；原手册§7.2纸7-4/PDF272，§7.4纸7-9–7-24/PDF277–292，§7.5.10–11纸7-46–49/PDF314–317，§7.8纸7-63/PDF331。

自动生产框架与单工序刀路是两个层次：主轴加工当前件前端，副轴可加工上一件背面并排出，再同步接当前件、夹持、切断、退回。模板中的“主轴加工程序/副轴加工程序”是待填空白，不能说加工刀路已经存在。

### 两通道按会合点读

| 等待点 | 主轴前置动作 | 副轴前置动作 | 放行后 |
|---|---|---|---|
| M501 | 前端完成，切断刀定位并调用副轴 | 初始化并到接料配置 | 旧件排出 |
| M502 | 等待 | 排出及退回 | 主轴开启同步并确认速度 |
| M503 | M56、按需M54、M53 | 等待 | 副轴接近夹持位置 |
| M504 | 等待夹持 | 到位执行M20 | 主轴切断及M42阶段 |
| M505 | 切断检测阶段 | 保持夹持等待 | 副轴带件退回 |

同一横行不是同时执行；同号等待是同步点。等待码本身不执行夹紧/切断，也不替代实际完成反馈。表只在两边斜杠段都实际执行且每分支可到达条件下成立。

### 容易混淆的动作组

| 组 | 区分 |
|---|---|
| G300/G150/G310/G28 | G300主轴加工原点复位含实际运动；G150建立Z工件坐标而非再移动；G310副轴加工原点复位；G28 W0仍会经零增量中间点返回参考点 |
| M56/57与M54/55 | 前者旋转速度同步ON/OFF，后者位相同步ON/OFF；都不能直接当Z轴同步 |
| M53与M20 | 前者速度到达确认，后者副夹头关闭；速度确认不证明夹持深度或位置正确 |
| M60/61/62与M95/96 | 前者送料转矩OFF/ON/换料；后者余料检查开始/结束 |
| M97与M99 | 本机前者工件计数，后者子程序返回；不能套其他机床的通用习惯 |
| M05与M105 | 主轴停止及冷却OFF / 副轴停止；互不替代 |
| M90001与M94 | M9连续四位形式调出副轴程序，例为O0001；M94现有资料记录为用户本机切料头入口，但内部调用未知 |

### 不能静默抹平的疑点

- GOTO99按无条件跳转会越过副轴加工段，不是天然“仅第一件跳过”；末件收尾也未完整设计。
- 照片含备选值/机型写法：X38/X120、T2100/T9900、M20001/M90001、Z192/300。M17和M20001未查到本S20A定义，不能合成为可执行代码。
- M60后未显示M61；切断前缺明确G97；M505放行副轴后才检查余料并M55/M57，与手册例解除同步时序不同，须核整个循环，不能直接判定可用或必错。
- G300照片“加工长+刀宽+0.2”不是手册通用行程公式。手册对所需加工行程及导套配置另有规定。
- 切断Z必须统一刀刃参考，不能一律“总长+刀宽”；X−2在直径编程意味着越中心径向1mm，也不通用于训练例空心件的X2。
- 模板的原图未在本文件夹出现；上述是笔记保存的转录和当时核对结论。

## 料头处理与三种例程版本

来源：S205A_切料头程序_原文与解释.md及3页原文摘录。

M95 → /M92 → M96构成手册余料检查调用链；符合缺料条件时进入O9002，M99返回。现有记录中的M94切头入口与手册O9002之间没有已查明的映射。

动作链：切断刀退让 → 余料退出导套 → 松主夹头 → 送料机换棒 → 主夹头关闭 → 恢复送料转矩 → 旋转开冷却 → 材料前进 → 切断刀接近并确认到速 → 切掉料头 → 返回。

| 项目 | 原PDF286 纸7-18 | 原PDF359 纸7-91 |
|---|---|---|
| 换料后延时 | G04 U1.0 | G04 U2.0 |
| 材料前进 | G98模式 F1000 | G99模式 F0.3 |
| 切入 | G99 X19 F0.3及省略 | X19、M12、X14 F0,03及省略 |

两版不可拼接成生产程序。原PDF358纸7-90是长件加工中途先接住切断再换料的双通道O9003/O9005例，不同于普通O9002。

原359图中M10旁注“打开”与M码表及358“关闭”冲突；应按M10关闭理解并标原旁注疑误。F0,03逗号通过358的F0.03可理解意图，不能直接抄逗号执行。原图有省略符号，不能当完整代码。W−50/W50是Z增量退料/送料距离，不是料头长度；图5–10是此图料头示意，不是统一切头标准。

## 建议纳入的自测题及答案

1. 外径从φ12到φ11.8，单边去多少？0.1mm。
2. 2mm槽刀以低Z刃作基准，成品槽Z2–7，远壁对应参考Z多少？5mm；若粗槽两壁各留0.1，粗终点4.9mm。
3. φ3、118°钻尖最终到Z31.4，完整直孔多深？约Z30.499；先解释钻尖h≈0.901。
4. 旧成品背面Z30，新Z0同此面，旧切断粗面Z30.2对应新Z多少？−0.2。
5. D18、d14、L40锥度？1:10。D16、L30、1:20小端？14.5。
6. 锥面Z10/30实测12.98/14.98，平均锥度变了吗？未变，仍0.1；整体偏小0.02。
7. M56是否Z1/Z2同步？否，是主副轴旋转同步。
8. 同号M504两侧均到达是否证明尺寸/夹持都合格？否，只证明程序会合条件，仍要相应机械状态确认。
9. G04 U1与普通运动U1区别？前者延时，后者在对应坐标模式下为X增量。
10. O8102能否原样放到副轴通道？不能；其定义是主轴翻面重新装夹。
11. 只见M94可否认定每循环切一次且调用O9002？不能，具体内部逻辑未取得。
12. GOTO99位于副轴加工段之前，有何结果？按无条件跳转语义跳过该段。
