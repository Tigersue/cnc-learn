# 走心机总导师技能：本地资料审阅建议

审阅日期：2026-11-04。只读检查了代表性专题、两个识图编程案例、自动加工模板，以及18个`tsugami-s20a-*`技能入口；未重读全部PDF扫描页。以下是技能设计建议，不是新的机床操作依据。

## 1. 总导师与现有18模块的关系

建议新建一个`swiss-lathe-mentor`之类的总导师技能，负责耐心教学、识图、工艺推理、编程组织、核对与学习延续。具体机床的代码、按钮、补正、规格及操作必须按需加载现有模块和对应原页。不要把18个技能的重复约束与完整指令表复制进新技能，避免资料版本漂移和上下文过重。

通用的是“从图纸→尺寸链→夹持与刀具→工序→刀位→程序→核查→首件反馈”的方法；津上S205A/S206A参数与M码不是通用走心机规则。

## 2. 应固化的教学行为

- 先讲工件要变成什么，再讲刀具和代码；以“这一步切哪里、为什么这样安排、结束在哪里、下一步从哪里来”串起动作，不先甩一整页程序。
- 依用户问题深浅回答。概念问题先给一个核心解释和简单算例；要完整方案时再展开工艺表、坐标表、程序及验证。不要每问一句都强制完整审查表。
- 每个关键数字交代来源：图纸直接标注／尺寸链推导／手册原例／用户现场确认／教学假设；显示单位，必要时说明直径量或半径量。
- 解释增量用“当前参考点→目标参考点→目标减当前”，并追踪模态循环和子程序执行后真实起点。不能把上一切削终点当作下一循环起点。
- 将实形工件、切削动作、最终特征、程序行对应起来。螺纹不能只画侧视直线：需要解释工件/刀具谁旋转、轴向前进、导程及牙槽/牙顶，必要时给螺旋与牙形局部图。
- 用户说“横向/纵向比对”时，按同类工序或代码分类比较／按类别逐层深入理解，不解释成X/Z走刀方向（该偏好来自本轮主代理历史回看）。
- 出题用于检查理解，不用考试口吻；答错时定位到具体误解，换工件/数字讲一次，避免仅重复定义。
- 图、动图与程序共享同一坐标假设和数值。精确刀路用可计算绘图；教学暂停、慢放与实机单段动作要分开。

## 3. 识图与工艺的关键规则

- 不按图片像素比例猜缺失尺寸；视图可能左右翻转。先识别投影、基准端面、中心线、截面、尺寸链、公差、粗糙度、材料、螺纹与去毛刺要求。
- 将已读清、计算推导、歧义待确认分开。先推进独立可确定的轮廓和工艺，不因一个未知值就停止所有学习；但不能默填影响碰撞、夹持、有效螺纹或验收的关键值。
- 先画成品名义轮廓，再算刀具参考点；槽宽与槽距、槽刀基准刃、另一侧刃实际覆盖、刀尖圆角和让空必须一起核对。不要把成品槽侧壁Z直接复制为宽槽循环终点。
- 走心机显示/程序中的刀具相对工件路径，不等于刀架真实移动方向。主轴、副轴、前动力头、背动力头、同步轴的对象要明确。
- 工艺排序结合细颈刚性、孔深排屑、导套支承、夹持位置、切断带、背面余量及刀具可达性说明原因；不能只按图纸由右到左机械排刀。
- 保留用户指定的装夹与工序选择。最新历史个案已要求副轴攻M10且不二次装夹（主代理回看），应据此研究该工件方案；把用户现场声明与手册标准配置差异记录为待核对能力，不能擅改为翻面，也不能固化为所有副轴均可攻M10。

## 4. 程序核对的最低有效内容

按任务适用性检查，避免每次照抄长清单：

1. 明确代码制、单位、平面、直径/半径、主副通道、工件原点、轴正向、刀具参考点、刀号和补正。
2. 读已有完整前文/子程序，记录运动模态、G98/G99、G96/G97及限速、主轴/动力头状态、补正状态。不用节选推断完整程序已初始化。
3. 所有进退刀段用整把刀具/刀杆/夹具/导套/夹头核对空间，不只看刀尖端点；快移是否可能跨料，循环中间动作和最终位置是否有原文依据。
4. 有限刀宽、真实刀尖R、粗精余量、通孔穿出与钻尖高度、有效螺纹长度、切断刀宽及背面余量分别算清。
5. 子程序标入口/出口状态、净位移、次数；检查最后一槽是否多走一节距，子程序M99与主程序结束/循环关系。
6. 双通道分别建状态表，配对等待码和分支可达性；第一件、正常件、最后一件的旧件加工/排出/接料不能只看正常循环。等待码与延时不证明机械夹紧或完整切断。
7. 教学参数保留假设；生产切削条件依据真实材质、刀具厂家、悬伸、冷却、刚性和设备限值。算术验证≠实控仿真≠干涉验证≠首件合格。
8. 未确定关键现场坐标时用清楚的“待填写”说明或不供执行的片段，避免给看似完整、实际含危险默认坐标的NC文件；不宣称可直接投产。

## 5. 代表性来源与可复用教训

### `培训练习1编程/图纸识读与程序说明.md`

- 有总长30的尺寸链、孔口倒角的几何解释、成品轮廓与宽2mm刀具参考点转换、φ3/118°钻尖完整孔径深度。
- 明确O8102是主轴翻面重新装夹，不是副轴程序；新Z0及粗面新Z−0.2证明翻面必须重建坐标。
- φ3通孔使该例切到X2即可切透。**X2、S1000、F值、刀号、Z31.4、刀宽2、余量0.2、翻面方案均为个案，不能做通用规则。**

### `散热槽螺纹工件编程/程序说明与坐标表.md` 与 `O0100_重复切槽_刀尖R0.1教学.nc.txt`

- 将刀宽1.5、真实刀尖R0.1、成品R0.5、参考路径R0.6区别开，校核两侧刃及子程序净位移。
- 入口X18/Z=A，出口相同；可以示范让刀与增量当前状态追踪。
- **R参考=R成品+R刀尖只对该凸圆角及该参考定义成立，不能固化为所有圆弧统一相加。**同样不能把旧教程中G40当作“不需要任何刀具几何补正”。
- `尺寸核对与编程待确认.md`开头已声明它保存最初问题清单，当前成果在后续文件。新技能应先识别最新版本，避免把已确认项重新发问。

### `G75学习资料/六槽槽口R1/程序说明.md`

- 独立采用+Z向右，负Z入料；刀宽向−Z。与其他笔记常用津上+Z向左不同。必须逐题声明坐标，不能用既有练习覆盖新题。
- 有左右刃参考点、三列覆盖、子程序W净位移与六次调用示例。
- 理论尖角教学，未给实际刀尖R；**不应声称已保证成品R1**。

### `G71学习资料/G71粗加工循环学习笔记.md`

- 同字母在不同段有不同意义；G71首行U是半径切深，次行U在本例是直径余量；P/Q为段号。轮廓写成品，不能先加余量再让循环叠加。
- Type I/II与单调性必须核版本与选项，圆弧中间极值也需考虑，W0不等于Z0。
- **这份格式是FANUC控制器补充，津上代码表列出G71不等于津上正文已详细给出格式。**

### `G74学习资料/G74端面切槽循环详解.md`

- P关联X径向、Q关联Z；G74与G75不是P/Q互换。IS-B公制0.001整数单位是适用前提，不是任何系统的通用事实。
- 最深位置、回退后位置与新增材料深度不同；P/Q不由毛坯边界自动起算。循环结束点必须依原图，不凭动画想象自动返回。
- 中心啄钻省略X不等于自动对中；钻尖终点不等于完整孔径深度。

### `G92学习资料/G92_M6x1_看工件学程序.md`

- 先工件再两道工序，说明牙顶由前序外圆形成、G92的X控制牙槽底；X4.60不代表把光杆全车成φ4.60。
- 图纸螺纹段6与程序Z6.5分开，不能编造多0.5的来源。**X4.60不是所有M6×1的标准合格牙底径。**

### `G184_G186动力头刚性攻丝学习资料/G184与G186_动力头刚性攻丝图文详解.md`

- 主副主轴和动力头分开；按谁旋转/谁进给/孔方向选功能。G184 X1直径量与G186 Y2半径量不同；F仍为每转实际导程。
- Q在M129里是旋向，在攻丝循环里是延时。刀位传动影响旋向，不能“右牙永远Q0”。**G186背面横向工序不能推广为所有背驱攻丝。**

### `自动加工模板学习资料/自动加工模板_逐段详解.md`

- 原图备选值、斜杠、留空、条件跳转及无条件GOTO都要原样保留分析，不能静默拼成一台机的程序。
- M94是用户现场确认切料头入口；手册O9002为换料调用例，二者映射未查明。不能说M94每循环都切料头或必调O9002。
- M56/57旋转同步、M54/55位相同步不等于Z轴同步；等待码并非每一横行同时执行。
- G300实际运动与G150坐标建立区分；模板长度+刀宽+余量不是G300万能行程式。
