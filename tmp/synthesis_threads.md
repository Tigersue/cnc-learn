# 螺纹与刚性攻丝资料综合核对稿

供主文档编写。已逐份读完所分配目录全部 7 份 Markdown、2 份 NC，并目视核对关键原页图片。此稿不另拟生产程序。

## 1 可直接用于正文的学习主线

先分清成形方法，再看旋转对象，最后读坐标和参数。

1. 单点车螺纹：工件旋转，牙型刀与主轴同步沿轴向走刀。同一条螺旋反复加深，刀尖无需沿剖面锯齿上下跳。
2. G92：一行包含一刀的切入、同步切削、横向退出、轴向返回；逐刀的 X 由人给。
3. G76：两行给出分刀规则与目标，由复合循环组织多刀；不是把 G92 换一个号码。
4. 内外牙：方法可相同，但切深与退刀方向相反。外牙往轴心挖，内牙往孔壁挖。
5. 刚性攻丝：丝锥与工件之间的旋转和轴向进给同步，攻入与反转退出都按导程配合；不是单点刀切完横向退让再返回。
6. G84、G184、G186：重点比较“谁转、谁进给、在哪一侧、坐标是直径还是半径”，不能只背代码。

## 3 坐标与分刀共同底层

本资料主轴侧沿用津上右端面 Z0、进入棒料为 +Z、X 直径显示。示意图多为刀尖相对工件的轨迹，不表示走心机真实 Z 运动总由刀架完成。

| 问题 | 外螺纹（图示 +X 侧） | 内螺纹（图示 +X 孔壁） |
|---|---|---|
| 加深 | X 减小 | X 增大 |
| 切完退刀 | X 增大，离开外圆 | X 减小，收向孔心 |
| 第一刀名义径向切深 | (切前外径−本刀X)/2 | (本刀X−前孔直径)/2 |
| 后续新增径向切深 | (上刀X−本刀X)/2 | (本刀X−上刀X)/2 |
| 返回通道 | 外圆外侧 | 孔内，整把刀具有间隙 |
| 牙顶和牙底 | 大径在牙顶，小径在牙底 | 小径在牙顶，大径在牙底 |

循环起点是间隙位置，不是材料表面。由返回点与目标点之差不能直接算第一刀实际吃刀量。重复相同 X 仍是一整刀，新增名义切深为零，但可能因让刀而仍出屑。

## 4 G92 一页正文候选

**记忆句：一行一刀，X 定本刀深度，Z 定轴向终点，F 定导程，切完回起点。**

格式 `G92 X(U)… Z(W)… F…` 中 X/U、Z/W 是二选一；U/W 从循环起点算增量，不是从上一刀目标继续加减。

厂家 M6×1 原例先由 T18 完成名义 φ6 外圆，再由 T06 车螺纹。起点 X7、Z−2；`G92 X5.40 Z6.5 F1.0`，继而 X4.96、X4.70、X4.60、X4.60。

| 刀次 | 本刀 X | 新增单边/mm | 累计单边/mm |
|---|---:|---:|---:|
| 1 | 5.40 | 0.30 | 0.30 |
| 2 | 4.96 | 0.22 | 0.52 |
| 3 | 4.70 | 0.13 | 0.65 |
| 4 | 4.60 | 0.05 | 0.70 |
| 5 | 4.60 | 0 | 0.70 |

第一刀四段：X7/Z−2 → X5.40/Z−2 → X5.40/Z6.5 → X7/Z6.5 → X7/Z−2。四段是简化刀尖轨迹；末端修牙、加减速和整刀形状未展开。

最易错三点：① X7 是循环起点，不是切前外径；② X4.60 只是原例末刀值，不是所有 M6×1 的通用牙底；③ Z6.5、从−2到6.5的8.5 mm指令行程、图上6 mm部位长度不同，均不能自行当完整有效牙长。原例另有 T06 Z 补正1.0，原文未给出将6.5换算成6的确定公式。

对基础例起点 X16/Z−2，目标 X12/Z10，用增量是 U−4/W12；下一刀到X11应 U−5，不是U−1。G92后单独写X会继承循环，退离时要明确G00，不套用G80。

出处：`G92学习资料/G92螺纹切削循环图文详解.md`；`G92_M6x1_看工件学程序.md`；原段 NC 20 行含前序与螺纹，仍非完整整机程序。原手册§7.5.7.2 7-43（PDF311）；§7.9.1(2) 7-65～66（PDF333～334）。

## 5 G76 一页正文候选

**记忆句：第一行定分刀，第二行定目标；X 是直径，牙高和切深是半径量。**

资料是自拟 M10×1.5，使用 FANUC 两行式，非津上加工原例。明确假设切深整数输入单位0.001 mm。

```
G76 P020060 Q50 R0.05;
G76 X8.160 Z16.5 R0.0 P920 Q250 F1.5;
```

| 地址所在行 | 含义 | 本例 |
|---|---|---|
| 第一行 P mm rr aa | 精加工次数／修牙量／刀尖角 | 02次／00／60° |
| 第一行 Q | 最小粗切深度，径向 | 0.050 mm |
| 第一行 R | 精加工余量，径向 | 0.050 mm |
| 第二行 X、Z | 末刀目标直径、轴向终点 | X8.160、Z16.5 |
| 第二行 R | 锥度量，带符号半径差 | 0为圆柱 |
| 第二行 P | 总牙高，径向 | 0.920 mm |
| 第二行 Q | 首刀切深，径向 | 0.250 mm |
| 第二行 F | 导程 | 1.5 mm/rev |

几何核对：以名义φ10起算，10−2×0.920=8.160；首刀参考X9.500；粗切累计0.870，对应X8.260，再径向去0.050到最终X8.160。X12返回点不参与总牙高计算。

P020060的02是末精加工总次数，不是粗切总刀数；首次末精加工去余量，后一次重复最终目标。00只表示修牙量0，仍然要退出；本例依赖预制退刀槽。60是刀尖角，不是“60°斜进刀”。rr=10表示1.0个导程，在F1.5时是1.5 mm。

本地动图只取五个代表深度，省略中间粗切，不代表总共五刀。原厂理想趋势 h_n≈首刀深度×√n，只用于理解后续切深逐步减小，实际受最小切深、余量和版本算法影响，不据此宣布现场刀数。

格式证据：FANUC B-64604EN-1/01 §4.2.7，纸面82～87（本地PDF96～101，关键96/97已目视核对）。本机手册只列G76功能；不要声称两行参数来自津上本册完整说明。保留现场增量单位、控制器版本、代码制核对。

出处：`G76学习资料/G76螺纹切削循环图文详解.md`、`G76_M10x1.5_螺纹工序教学片段.nc`。

## 6 内螺纹一页正文候选

**记忆句：先有孔，向孔壁挖槽；X 越大切得越深，切完先收刀，再沿孔内返回。**

资料自设通孔管件壁段Z0～6，出口外终点Z8，前孔φ9，返回点X8.40/Z−2。逐刀X为9.36、9.62、9.80、9.92、10.00、10.00；新增径向切深为0.18、0.13、0.09、0.06、0.04、0，累计0.50 mm。不是厂家内牙原程序。

四段为：端面外放刀 → 同步过孔 → 出口外收向孔心 → 沿孔内返回。不能把外牙的向外退刀动作搬到孔内，也不能仅凭刀尖X小于孔径就认定刀杆与对侧孔壁不干涉。

前孔φ9到名义X10的0.50 mm与M10×1基本内牙牙高0.5413 mm不是矛盾：后者从基本小径8.9175起算。公称M10不等于所有刀片最终X都填10。

纵向工序链：确认标准／公差／有效长度 → 钻镗前孔 → 入口倒角和末端空间 → 核刀杆最小孔径及整刀间隙 → 保持导程、固定转速和同步条件逐刀切削 → 精修去毛刺 → 按图纸用塞规及小径等测量。通孔出口退刀示例不可直接套盲孔。

原文讨论的“双头外牙照片”不等于内牙：原程序先车外圆且X递减；“去螺纹内毛刺”只是工序名称，不能据此判断是内螺纹。

出处：`内螺纹学习资料/内螺纹切削图文详解.md`；津上基础坐标PDF274，G92 PDF311；FANUC补充同步PDF38～40、G92 PDF51～53。

## 7 螺纹公式专页候选

先分四栏记：基本几何值、经验估算、工艺预加工尺寸、实测验收结果。任何一栏都不能自动替代最终程序X。

`导程 L = 头数 n × 螺距 P`；G92/G76的F填写L。单头P1用F1，多头P1仍按P1计算牙型，但双头的F为2，另需安排第二头相位。多刀加深不等于多头。

对于所述公制60°基本设计牙型：

| 几何量 | 关系 |
|---|---|
| 基本大径 | D=d=公称直径 |
| 基本中径 | D₂=d₂=d−0.649519P |
| 内牙基本小径 | D₁=D−1.082532P |
| 外牙圆弧牙底设计小径 | d₃=d−1.226869P |
| 内牙基本径向牙高 | (D−D₁)/2=0.541266P |
| 外牙设计径向牙高 | (d−d₃)/2≈0.613435P |

M10×1.25算得基本中径9.188，内牙小径8.647，外牙设计小径8.466，内牙牙高0.677，外牙牙高0.767 mm。它们不是6H/6g之类公差带上下限。

经验式冲突示例必须保留：若图片经验实际大径10−0.1P=9.875、小径10−1.3P=8.375，则两者实际径向差=(9.875−8.375)/2=0.750；0.65P=0.8125是从公称φ10起算，不能与0.750混称。同样，津上P1.25表列高度0.81及不同材料分刀表属于切削参考，不是ISO公差表。

预孔粗估：切削攻丝常见 D−P，挤压攻丝预孔通常更大；资料列D−0.5P只是估算，须按丝锥资料与材料选定，不作为成品小径。车内螺纹前孔也不能自动照抄攻丝预孔经验式。

英制换算：3/8-24大径9.525 mm，P=25.4/24≈1.05833 mm；仍称原英制规格，不改称公制M规格。#6-32大径=(0.060+0.013×6)×25.4=3.5052 mm，P=25.4/32=0.79375 mm。原图末尾0.635是40 TPI的结果，不能用于32 TPI。

出处：`内螺纹学习资料/螺纹尺寸计算_图片与S20A手册对照.md`。该文引用ISO724:2023公开预览§5，三菱基本牙型、YAMAWA预孔表等；综合时可写“依原资料所引基本设计牙型关系”，避免冒充本次另做标准合规审核。津上原表PDF362保留高度、材料条件。

## 8 G84 一页正文候选

**记忆句：工件转，Z1送；每转一个导程，孔底反转沿牙退出。**

本资料讲固定正面丝锥，主轴夹工件旋转，主轴箱随Z1进退；X0用当前补正对中心。不要把钻床“丝锥转且向下走”套到该配置。

用户截图核心段：`G99; M5; M29 S600; G84 Z6.0 P100 F1.25; G80;`。它是原图片段，不是经本次修正后的生产程序。

| 参数 | 正确理解 |
|---|---|
| M29 S600 | 刚性攻丝准备及攻丝旋转轴转速；600为原图数值 |
| Z6 | 终点坐标；端面Z0、补正正确时名义进入6 mm，非保证6 mm完整牙 |
| F1.25 | 每转实际进给1.25 mm；不能据此确定是M8 |
| P100 | 1 μm规格为0.100 s；0.1 μm规格为0.010 s |
| G80 | 取消循环状态；反转退出本已包含在G84内 |

G99 是本册明确要求，不是铣床式R平面返回选择。F须带小数点。n×L=600×1.25=750 mm/min，仅为同步段名义速度，不是推荐切削条件。

动作链：快移至R点 → 同步攻到底部 → 停止延时 → 反转同步退至R点 → 快移回起始点。截图省略R，原文允许省略，不能人为补出“快速到Z0”动作。原格式把R解释为起始水平到R点的距离；比较表不要统一写成各种循环通用的“绝对R平面坐标”。

需保留的片段问题：M13开启过切削液，但该机M05会关闭冷却液，原图M05后未见M08，不能认定攻丝时冷却仍开着。G18/G80前置状态可能存在于截图外，不判定必错，也不判定已齐备。

关键原图已目视复核：PDF322（7-54）格式、G99与小数点；PDF337（7-69）P单位；PDF281（7-13）M05关冷却并要求后续M08。出处 `G84端面刚性攻丝学习资料/G84端面刚性攻丝_图文详解.md`。

## 9 G184 与 G186 一页正文候选

**记忆句：184用前驱X1，186用背驱Y2；一个直径，一个半径，F仍是实际导程。**

| 核对项 | G184 | G186 |
|---|---|---|
| 本册名称 | 横向前面刚性攻丝，选配 | 背面横向刚性攻丝，选配 |
| 通道 | 主轴侧指令 | 背轴侧指令 |
| 旋转／进给 | CDF动力头／X1 | BD动力头／Y2 |
| 底部地址 | X，增量U | Y，增量V |
| 底部和R的数值 | X/U/R直径坐标 | Y/V/R半径坐标 |
| 准备 | M129 S… Q方向 | M129 S… Q方向 |
| 循环延时 | Q，例Q1.0为1s | Q，例Q1.0为1s |
| 进给 | G99，F为导程且带小数点 | 同左 |

M129里的Q是方向：Q0 CW、Q−1 CCW；循环里的Q是延时。G184页对右旋攻丝规定T02用Q−1、T01/T03用Q0，不能将“右牙一律Q0”或前刀位映射套到G186。

原例 `G184 X5.0 R20.0 Q1.0 F1.0`：R到X的数值差15，对应实际直线7.5 mm；若G186同样R20到Y5，则实际行程15 mm（这是按定义做的对比推导，不是修正原程序）。F1.25无论哪种均为实际每转1.25 mm，G184的X显示相应每转变2.50，不能把F翻倍。

原册两种M129功能格式均列转速MAX 2000 min⁻¹；仅如需要机型边界说明时保留，不作为通用推荐值。

明确纠错边界：PDF325～326写G186、Y2、Y/V/R半径；PDF327程序区却印G184 X…、G184和T0202，旁注仍为G186/Y2/Y5。这是原图可见的矛盾，不是抽取错误。本手册采用前两页定义解释，不自行把例程修改成可上机版。

型号边界：PDF41（2-15）S205A标准轴名无Y2，S206A有Y2；PDF29 S206A背面驱动构造图配合说明。应写“本册G186需要Y2及背驱选配，不能据S205A标题认定具备”。不要写“G186在S205A上使用X2”。

## 11 复习题可选

1. M6原例起点X7、切前φ6，第一刀X5.4，名义径向切深？0.30 mm，不能算0.80。
2. 内牙从X9.6到9.8，多切多少、向哪边退？0.10 mm；本图条件下向X减小方向收刀。
3. 双头P1用F多少，牙型公式用P多少？F2，仍用P1；另需第二头相位。
4. G76第一行P020060与第二行P920是不是同一种量？不是；组合码与牙高整数。
5. R0.05精余量在X直径上差多少？0.10 mm。
6. G84 P100一定是0.1秒吗？不一定；要核1 μm或0.1 μm规格。
7. M129 Q−1与G184 Q1.0是否都表示方向？前者方向，后者1秒延时。
8. G184 X显示每转变2.50，实际导程1.25，F要翻倍吗？不用，F1.25。
9. G186能否写成背面X2进给？本册定义为Y2，需对应轴和选配。
10. 指令从Z−3到16.5，完整牙长19.5吗？不是；这是指令行程，须另看入口、末端、基准和有效牙要求。
11. #6-32的螺距0.635对吗？不对，0.79375 mm；0.635对应40 TPI。
12. 丝锥未离牙时能否快速沿轴拔出？攻丝循环须反转同步退出，不套车牙刀的横向退刀动作。
