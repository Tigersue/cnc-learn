# 车削与切槽专题综合提要

## 证据范围与整体学习顺序

已完整阅读 G71、G90、G94、G74 两篇、G75 主篇、六槽槽口 R1 说明及两份 NC；已查看 G74 FANUC 原刀路页、津上 G94 原图，以及 G71 余量图、G75 刀宽图、六槽 R1 图。下列内容是对现有资料的综合整理。标为“原例”的数值保留出处；计算例沿用各资料的自拟前提，不应变成通用切削条件。

建议纵向顺序：坐标与模态 → G90 单刀四段 → G94 与 G90 对照 → G71 从单刀升级到轮廓分层 → G75 径向啄切与刀宽 → G74 轴向啄切与环槽 → 六槽 R1 综合练习。每学一项都回答：从哪里起、沿哪根轴主切、另一轴做什么、每次结束在哪、最终留下什么形状。

本批资料的通常前提是公制、ZX 平面、X 直径编程、津上主轴侧 +Z 向左深入工件。**六槽 R1 练习另采用 +Z 向右、负 Z 深入，必须单列坐标说明。** FANUC 原图也是 +Z 向右，不能把图中负号直接复制到津上教学坐标。机台手册封面、前言及文件名有版本差异；FANUC 0i-F 资料是补充解释，不能自动替代现场 0iTF Plus 版本与选项。

| 记忆重点 | 沿 Z 车，换 X 分刀 | 沿 X 车，换 Z 分层 | 写成品，让循环粗车 | 啄 X，沿 Z 排列 | 啄 Z，沿 X 排列 |

“车外圆用 G90、车端面用 G94”是动作入口；不能只凭最终外形判断用过哪个循环。G94 原例也可留下一个 φ8×12 的轴颈。先看主切方向，再看最终形状。

## 基础换算 一套公式贯穿所有例子

1. X 为直径坐标时：径向距离 = |X终−X始|÷2。例：φ18 车到 φ17，单边切深 0.5 mm。
2. 实料切深要用真实毛坯计算。起点 X20、毛坯 φ18、切至 X17：径向总移动1.5 mm，其中空行程1 mm，新增材料切深0.5 mm。
3. 直径余量与单边余量分开。φ12.3 留到 φ12，直径余量0.3 mm，单边余量0.15 mm。
4. 增量看执行时的起点。G90/G94 每轮回 A，因此第二轮 U/W 仍从 A 算，不是从前轮切削终点算。
5. G99 下 F 是 mm/rev；G98 下 F 是 mm/min。本机 G94 是刀路循环，不是每分钟进给开关。G99 示例换算：1200×0.08=96 mm/min，只作算术，不是推荐参数。
6. 终点尺寸不等于刀具覆盖边界。槽的真实边界 = 参考点位置 + 刀宽方向；先画出刀具参考角，才可算末列坐标。

### 同名字母横向对照

| 地址 | 出现位置 | 实际含义 |
|---|---|---|
| U | 普通 X/U 表达 | X 方向增量，本例为直径差 |
| U | G71 第一行 | 单边粗切深，半径量 |
| U | G71 第二行 | X 向精加工余量，本例为直径量 |
| U | G04 U0.1 原例 | 延时，不是轴移动 |
| P/Q | G71、G70 | 轮廓起止 N 段号 |
| P/Q | G74、G75 | X 径向量和 Z 轴向量，整数单位依增量系统 |
| R | G90/G94 图上 R | Rapid 快速运动标签，不是程序参数 |
| R | G74/G75 第一行 | 啄切小回退量 |
| R | G74/G75 带轴第二行 | 到底后垂直于啄切方向的让刀量 |
| R | G02/G03 | 圆弧半径 |

结论：**先读代码和所在行，再读地址字母。** 不可把一个字母固定背成一个意义。

## G90 与 G94 用同一个四段框架学习

两者直线例均为 R→F→F→R，第三段仍是切削进给。它可能切到台肩或沿已成形表面返回，不能当作“必定空走的快速退刀”。完成四段返回 A 与取消模态是两回事；后续明确 G00/G01 等同组运动方式。

### G90 津上原例

起点 A=(18,−1)，`G90 X16 Z10 F0.25`：

- A(18,−1)→B(16,−1)，X 快速。
- B→C(16,10)，Z 切削进给。
- C→D(18,10)，X 切削进给。
- D→A，Z 快速。

后续 `X12; X8;` 继承 G90、Z10、F0.25，各自完整循环并返回 A。原例起点 X18 不等于已证明毛坯直径φ18。F 单位要看前置 G98/G99。

### G94 津上原例

起点 A=(16.6,−1)，`G94 X8 Z4 F0.05`：

- A→B(16.6,4)，Z 快速。
- B→C(8,4)，X 切削进给。
- C→D(8,−1)，Z 切削进给。
- D→A，X 快速。

后续 `Z8; Z12;` 分别改变本刀端面位置，形成φ8、长12的轴颈；因为终点 X8，中心没有车掉。原图φ16毛坯，X16.6的径向间隙为0.3 mm；第一刀径向移动(16.6−8)/2=4.3 mm。

增量对照：第一刀 `U−8.6 W5`，后两刀 W9、W13，因为都从 Z−1 出发。若两次都写 W4，不能表达“每次再加深4”。

来源：津上 §7.5.7.1 和 §7.5.7.3，纸面7-43，原PDF311；G98/G99见纸面7-45，原PDF313。相近 FANUC F 手册补充单段模式一启动完成四段，动画中的逐步播放不能代表真实单段停点。

## G71 从逐刀尺寸升级为成品轮廓

### 两行各做什么

`G71 U0.5 R0.3`：设定单边切深0.5和循环退刀量0.3。

`G71 P100 Q160 U0.2 W-0.1 F0.08`：引用 N100～N160 的成品轮廓，直径留0.2、Z向带符号留量−0.1，并使用粗车 F0.08。

P/Q 轮廓写成品φ10，就写 X10；不能预先写 X10.2 再叠加 U0.2。后续 G70 也引用这段成品轮廓。粗循环中的 F/S/T 读取规则与 G70 不同；本例粗车取循环行 F0.08，G70 精车从轮廓段继承 F0.05。

### 与 G90 比较同一台阶轴

自拟成品：Z0～8 φ10，Z8～20 φ14，后方φ18。

- G90：人为先排长的φ14段，再排短的φ10段；各刀 X 由编程者写出。
- G71：先把成品节点写成 (10,0)→(10,8)→(14,8)→(14,20)→(18,20)，再给分层与余量规则。
- G71 本例 U0.2 对应粗车名义φ10.2、φ14.2；+Z 入料、W−0.1 对应台肩 Z7.9、Z19.9。
- G90 原练习的肩部余量是0.2，G71 原练习是0.1；这是不同教学设定，不能把结果差异误认成循环固有差异。

Type I 首段指定 X/U、不指定 Z/W；X、Z 轮廓须单调。Type II 首段同时指定两轴，Z 须单调，X 可形成符合要求的凹部，且要核实选项。需要指定 Z 轴但不位移时，原资料用 W0；Z0 是实际坐标，不能互换。圆弧内部极值也影响单调性。

切深层次由起点与轮廓计算，系统不会识别真实毛坯；不得把例图写成已确认的精确刀次数。轮廓末端φ18加余量成为名义φ18.2，但毛坯仅φ18，外面的“余量线”不是真实材料。

来源：G71 主笔记；津上代码表原PDF293确认列码，完整规则补充自本地 FANUC B-64604EN-1/01 §4.2.1，原PDF66～79；G70见原PDF88～91。不要把该补充格式说成津上正文完整原例。

## G74 与 G75 先固定轴 再分清啄切和换列

共同格式是两行；**P始终关联X径向，Q始终关联Z轴向，没有交换字母。** 公制 IS-B 假设下，P/Q 一个整数单位为0.001 mm，且所引格式不许小数点。X直径编程不改变P的径向性质。

| 观察动作 | G75 | G74 |
|---|---|---|
| 一啄新切多深 | P，径向 | Q，轴向 |
| 另一列隔多远 | Q，轴向 | P，径向 |
| 第一行 R | X径向小退 | Z轴向小退 |
| 第二行 R | 槽底 Z向让刀 | 槽底 X向让刀 |
| 固定单列省略什么 | 省 Z/W 与 Q | 省 X/U 与 P |
| 换列前退出 | 径向退出再移 Z | 轴向退出再移 X |

第二行 R0 仅取消槽底附加让刀，不取消首行小回退。两个 R 都不是圆角，也不是精余量。

### G75 径向算例

自拟毛坯φ20，起点X22，槽底X14，P500=径向0.5，首行R0.2=径向退0.2。

- 实料槽深=(20−14)/2=3 mm；起点到槽底=(22−14)/2=4 mm。
- 最深X依次21、20、19、18、17、16、15、14，前两啄尚未新增切入材料。
- 到X19后回退至X19.4；下一次工进到X18，径向走0.7，其中0.2重走、新切0.5。
- 不是 P−R=0.3 mm 新切深。

2 mm刀、低Z侧刃角为基准、槽壁Z10～16：末列参考点应是Z14，不能写Z16。Q1500=1.5 mm时列位10、11.5、13、14，覆盖10～12、11.5～13.5、13～15、14～16。4列中的最后列距缩为1 mm。总宽=参考点跨度4+刀宽2=6 mm。

若Q6000、参考点10→22，则列位10、16、22，形成三个分离槽；系统不会自动清空中间材料。

### G74 轴向与环槽算例

自拟起点Z−1、终点Z4、Q1000=1 mm，首行R0.2。最深Z为0、1、2、3、4；非最终啄回退到−0.2、0.8、1.8、2.8。总行程5 mm，实料槽深4 mm。每次小退并不等于全退到孔外。

环槽目标φ10～φ16、径向宽3 mm；刀宽1.5 mm、外径侧刃角为基准，向内排刀。末列参考X=10+2×1.5=13，不是X10。P1000=径向列距1 mm，参考X依次16、14、13；直径覆盖φ13～16、φ11～14、φ10～13。若错写X10，内侧刃达到φ7，槽会过宽。

中心啄钻须先把钻头对中X0，再省略循环行X/U/P；省略不等于自动对中。Z终点可能是钻尖位置，不等于完整孔径深度。

来源：G74两篇、G75主篇；本地 FANUC F 原PDF92～93为G74，94～95为G75。津上代码表列名但已查段落未给直接循环原例。所引手册禁止这两个循环应用刀尖R补偿；刀具几何/磨耗补正是不同事项。

## 两个综合案例的学习价值

### 手写断屑钻孔与 G74 相似但不等价

津上原PDF335原例：Z−1→Z2→Z1.8→Z6→Z5.8→Z10；首段F0.02，后段F0.04；孔底G04 U0.1。它能解释“深入、小退、再深入”，却不能直接压为一条固定Q/F的G74：新增深入量3、4、4不等，F有变化，孔底有延时，且原例W−0.2继承G01为工进回退，而G74原图标小退为快速。

关联页的正面T铣刀割槽、Z1/Z2同步切槽、深孔装置例，分别属于不同工艺与设备条件；名称含“槽/钻”不证明调用G74/G75。深孔原PDF344中Z23.5后出现Z−30.0 F0.05，原资料保留为待核点，不能默改为Z30。

### 六槽与两侧 R1 练习

独立坐标：+Z向右，刀宽1.5向−Z延伸，右刃为参考，理论尖角、G40。

首槽侧壁Z−5与Z−9，槽宽4；参考点−5、−6.25、−7.5，覆盖并集为−9～−5，相邻重叠0.25。三次均为单列G75，每次先径向退至X22再换Z。

右口R1由右刃直接走 X20/Z−4→X18/Z−5。左口轮廓实际由左刃走 X20/Z−10→X18/Z−9，但程序右刃参考点要加1.5，成为Z−8.5→−7.5。R1是径向变化1，因此X直径变化2。

每次子程序W代数和为−10；主程序从Z+5重复6次，槽位−5、−15、−25、−35、−45、−55。程序 `M98 P060100` 按资料所引四位子程序格式表示 O0100 共6次；不能把P与G74/G75长度或G71段号混用。

该例的价值是综合练习刀宽基准、相对位移累计、子程序次数与圆弧。真实刀尖R尚未提供，程序是理论尖角教学，不得标为实际R1精度已验证。G02/G03还依赖实际刀台与观察方向，不按纸面顺逆就推广。

## 便于复习的辨错题与答案

1. X20起点、φ18毛坯、G90第一刀X17，单边切深是1.5还是0.5？答：实料0.5；1.5是包括空隙的径向移动。
2. G94后只写Z8，是普通定位吗？答：循环仍有效时执行下一轮四段。
3. G90的第三段能画成快速退刀吗？答：不能；原图为F，可能切台肩。
4. G71两行分别U0.5和U0.2，哪个是直径余量？答：第二行U0.2，单边余量0.1；第一行单边切深0.5。
5. G71目标φ10且U0.2，轮廓写X10还是X10.2？答：X10。
6. G75 P500与G74 P500在IS-B下是否都径向0.5？答：是；但前者是啄切量，后者是换列量。
7. G75首行R0.2、第二行R0，是否不再小退？答：仍小退，只取消槽底附加让刀。
8. G75用2mm刀加工Z10～16，低Z刃角为参考，末列写Z16吗？答：Z14。
9. G74外侧参考刀宽1.5，加工φ10～16环槽，末列写X10吗？答：X13。
10. G74省略X/P会自行对中吗？答：不会，钻头须预先对中。
11. 六槽练习负Z与主笔记正Z是否互相矛盾？答：题设坐标不同，必须各自标注，不能混用。
12. 教学动画暂停代表实机每啄停下吗？答：不代表。
