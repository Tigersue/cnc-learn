| 分组 | 内容 | 原稿 |
| --- | --- | --- |

| [02 O1068 分段拉料](带注释/02_O1068分段拉料/) | 三段外圆车削、两次拉料、副轴接料切断。主轴原稿 M30 后附带的 C 轴 31 等分铣槽另存为片段 | `laliao主轴.TXT`、`laliao.TXT` |

## 对照原稿时留意

- **01 组**第一轮 M507～M510 双侧顺序一致。主轴末尾还有一轮 M509/M510，副轴材料缺对应段。副轴回参考点前的松夹动作和旋转同步解除动作也有待补证。
- **02 组**每轮拉料用 M540、M542、M544、M546、M548，接料切断用 M504～M512 和 M599。主轴原稿有两个 N17，副轴调用及主轴部分等待带有跳段符 `/`。铣槽片段缺程序号和独立调用入口，M223/M225 的定义待按对应机台核对。
- **03 组**主轴写 M91234，按 S20A 的 M9 加四位程序号规则对应副轴 O1234。副轴片段正文缺程序号，虽然 M507～M510 顺序一致，调用关系仍待确认。

津上 S205A/S206A《3281-LTQ0C-05》§7.4 的 M 码表和详细说明用于核对通道动作。旋转同步见纸面 7-16（原 PDF 第 284 页），Z1/Z2 同步见 7-19～7-20（原 PDF 第 287～288 页），副轴调用及等待码见 7-12、7-24（原 PDF 第 280、292 页）。
