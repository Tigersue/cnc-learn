# 螺纹尺寸计算：图片经验式与S20A手册对照

依据用户新图、津上S205A/S206A 3281-LTQ0C-05手册，以及ISO公制螺纹设计牙型资料。本文只讨论图片中的公制60°普通螺纹及英制尺寸换算，不把图片里的经验公式当成厂家规定。

## 先分清三种数值

| 数值类别 | 用途 | 不能混淆的地方 |
|---|---|---|
| 标准基本尺寸 | 建立公称大径、中径、小径与牙型的几何关系 | 不等于成品公差上下限 |
| 加工经验值 | 粗估实际螺纹大径、牙底目标、切削深度 | 不保证特定刀片与公差合格 |
| 攻丝预孔 | 为切削或挤压丝锥预留材料 | 不等于所有工艺的成品小径 |

符号：外牙大径d、中径d₂、小径d₃；内牙大径D、中径D₂、小径D₁；P为螺距，h为径向深度，尺寸单位mm。图片按经验式得到的实际大径另写d实际，避免与标准基本大径混读。“大径”是尺寸名称，不应在引用图片公式时改写为“外圆”。

## 图片中的外牙M10×1.25

图片按公称直径10、P1.25计算：

| 图片公式 | 算术结果 | 应怎样理解 |
|---|---:|---|
| 实际螺纹大径≈公称直径−0.1P | 9.875 | 图片给出的实际大径经验估算，不是标准大径上下限 |
| 牙底直径≈d−1.3P | 8.375 | 经验性车牙底径估算，非通用最终X |
| 牙高/车牙深度≈0.65P | 0.8125 | 经验深度，必须说明从哪个直径起算 |

三条式子的起算基准不能混用。若按图片经验式取实际螺纹大径9.875、牙底小径8.375，则两直径间的径向牙高为：

```text
(9.875−8.375)/2 = 0.750 mm
```

不是0.8125 mm。0.8125是从公称大径φ10算到小径φ8.375得到的径向差。若从实际大径φ9.875径向切入0.8125，几何包络小径会变成φ8.250，该数只是用于说明基准差异，不是加工建议。

本处术语更正不改变原算术结果：公称大径10.000、图片经验实际大径9.875、图片经验小径8.375；后两者对应径向牙高0.750 mm。0.8125 mm应另列为从公称大径起算的经验深度，不能与0.750混称。

## 公制60°螺纹的标准设计牙型关系

ISO 724:2023 §5给出的基本尺寸关系为：

```text
大径基本值：D = d = 公称直径
中径：      D₂ = d₂ = d − 0.649519P
内牙小径：  D₁ = d − 1.082532P
外牙小径：  d₃ = d − 1.226869P   （圆弧牙底设计牙型）
```

由大小径差计算径向牙高：

```text
内牙：H₁ = (D−D₁)/2 = 0.541266P
外牙：h₃ = (d−d₃)/2 ≈ 0.613435P
```

注意0.649519P在中径公式中表示“大径到中径的直径差”，不能不加区别地把它当作标准径向牙高。

以M10×1.25为例：

| 基本几何项目 | 数值/mm |
|---|---:|
| 公称大径 | 10.000 |
| 中径 | 9.188 |
| 内牙小径 | 8.647 |
| 外牙圆弧牙底小径 | 8.466 |
| 内牙径向牙高 | 0.677 |
| 外牙径向牙高 | 0.767 |

这些是按设计牙型计算的基本值，仍须按图纸公差等级确定允许范围，不是直接给刀尖坐标。

来源：[ISO 724:2023公开预览，§5，纸面第2页](https://cdn.standards.iteh.ai/samples/85104/9815392ad8904c9aa23cf7727e7b1dde/ISO-724-2023.pdf)。

## S20A手册中的0.65是什么

津上§7.10.2“螺纹切削计算表”，纸面7-94（原PDF第362页），表列高度大体接近0.65P，实际应按原表读取，不能强行视为统一精确公式。

| 螺距P | 手册“高度”/mm |
|---|---:|
| 0.5 | 0.32 |
| 0.7 | 0.45 |
| 0.8 | 0.52 |
| 1.0 | 0.65 |
| 1.25 | 0.81 |
| 1.5 | 0.97 |
| 1.75 | 1.13 |
| 2.0 | 1.30 |

P1.25列的分刀安排：

- 有色金属：0.32＋0.22＋0.14＋0.08＋0.05＝0.81 mm。
- 铁材：0.22＋0.16＋0.12＋0.08＋0.08＋0.07＋0.05＋0.03＝0.81 mm。

这是手册的切削分次参考表，不是ISO成品尺寸公差表。该页没有说明完整牙底轮廓，也没有明确把它限定为某种内/外牙设计牙型及刀片；不能据此把所有内牙标准牙高写成0.65P。

## 图片中的内牙M8×1

标准基本几何：

```text
D  = 8.000 mm
D₂ = 8−0.649519×1 = 7.350481 mm
D₁ = 8−1.082532×1 = 6.917468 mm
H₁ = (8−6.917468)/2 = 0.541266 mm
```

图片里的数值则是工艺估算：

| 图片写法 | 数值 | 作用与限制 |
|---|---:|---|
| “实际大径”≈D＋0.1P | 8.1 | 可理解为某工艺的牙底目标估算；不是标准基本大径，不保证最终X8.1合格 |
| D−P | 7.0 | 常见切削攻丝预孔粗估 |
| D−0.9P | 7.1 | 更大的预孔候选估算，仍须按图纸及刀具资料选定 |
| D−0.5P | 7.5 | 挤压攻丝预孔粗估，不能当成品内牙小径 |

切削丝锥以去除材料成牙，挤压丝锥通过材料塑性流动成牙，因此后者的预孔通常更大。挤压前孔径不等于挤压后小径；“7.5±若干”也不能不查刀具就统一采用。

例如YAMAWA所查表M8×1、G7丝锥列，100%/90%/80%牙高率对应预孔7.48/7.54/7.59 mm，说明选值与牙高率和丝锥等级有关；厂家也要求结合材料、硬度、形状和加工条件调整。这只是解释表的例子，不是本件选定值。

来源：[YAMAWA挤压攻丝预孔表](https://www.yamawa.com/Portals/0/images/download/holesize/en/technical-contents-16.pdf)。

## 从尺寸换算到X值

津上程序原点页明确X采用直径指示：纸面7-6（原PDF第274页）。因此：

```text
外牙径向切入 h = (切前实际外径 − 本刀X) / 2
内牙名义径向切入 h = (本刀X − 前孔直径) / 2
```

适用前提是刀尖坐标和几何基准已明确，实际切屑厚度与刀片轮廓、进刀方式另有关联。外牙X9.0到X8.8只新增0.10 mm径向切入；内牙X7.6到X7.8也只新增0.10 mm。

手册§7.5.7.2纸面7-43（原PDF第311页）定义G92的F为导程：

```text
导程 L = 头数 × 螺距 P
G92的F = L
```

牙型尺寸公式用P；双头P1时仍以P1计算牙型，但G92使用导程2，即F2。多刀加深与多头分相位是不同问题。

## 英制分数规格3/8-24

```text
基本大径/mm = (分子÷分母)×25.4
螺距P/mm = 25.4÷每英寸牙数TPI
```

3/8-24：基本大径(3÷8)×25.4＝9.525 mm；螺距25.4÷24＝1.058333… mm。

这表示原英制螺纹的尺寸换成毫米，不是把其标准名称改成“M9.525×1.058”。原规格、牙型、公差及量规仍按原标准确定。

## 美制编号螺纹#6-32

编号不是毫米，也不是6/32英寸。常用编号机螺纹的基本大径换算：

```text
d/in = 0.060＋0.013×编号N
d/mm = (0.060＋0.013N)×25.4
P/mm = 25.4÷TPI
```

#6-32：

```text
d = (0.060＋0.013×6)×25.4
  = 0.138×25.4
  = 3.5052 mm
P = 25.4÷32 = 0.79375 mm
```

图片前面写约0.793，最后却写成0.635，前后不一致。0.635＝25.4÷40，对应40牙/英寸，不是32牙/英寸。应保留#6-32的原规格，只注明毫米换算值d3.5052、P0.79375。

编号公式来源：[Atlantic Workforce Partnership机加工公式表](https://www.gov.nl.ca/atcd/files/MCH-L1-Formula-sheet.pdf)。

## 使用公式的顺序

先读清螺纹标准、公称直径、螺距、头数与公差；查基本尺寸，再查公差；按刀具和材料选择前序孔/外圆及分刀；将径向位移转换成X直径变化；最后通过相应量规与尺寸检查确定成品。

图中的加工口诀可帮助估量，但标准基本尺寸、工艺预加工尺寸与程序最终X值应分别记录，不能用同一个“实际直径”混写。
