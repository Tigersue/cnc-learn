# 我的加工学习与编程工作流

用于津上 S205A/S206A 与 FANUC 车床的识图、工艺、刀路学习和程序审阅。在聊天里一次解决一个问题。从当前工序进入，接着用已经确认的尺寸、基准和编号。

## 我怎么开始

| 我发什么 | 从哪里开始 |
| --- | --- |
| **继续** | 看当前聊天最后确认的工序、动作或程序行，接着往下讲。换了聊天，就用最新专题记录和交接进度接上。 |
| **P3 怎么来的？这行 W 为什么是负的？** | 用这个点或原行号定位，只拿相关图、点位和代码。先说刀从哪到哪，再代入本段数字。 |
| **看这张图，先做这道工序** | 读当前特征的尺寸和公差，确认基准、通道、刀具及参考点，先画清这道刀路，再写代码。 |
| **逐行讲这段程序** | 保留原码、原行号和调用关系。逐段说明入口、动作、留下的形状和返回位置。可疑行标出依据和待核条件。 |
| **把这几段合起来** | 用已确认的工序段整合，复核换刀、重定位、模态、子程序返回和主副轴交接。 |
| **把这两个循环放一起看看** | 横向比较同类方法的用途、动作、参数和选用条件，例如 G74 与 G75。纵向按工序 → 方法 → 指令 → 参数 → 实例 → 验证讲。 |

## 一道工序怎么走

1. **先看工件。** 找这一步要留下的面、孔、槽或螺纹，明确尺寸从哪量、材料在哪侧。沿用本件已确认的装夹和工序安排。把关键依据标成「图纸/原文明示」「计算」「教学假设」或「待确认」。本机功能先查津上《S205A/S206A 说明书》3281-LTQ0C-05，语法再查匹配版本的 FANUC 资料。引用记录章节、纸面页码和原 PDF 页序。
2. **再定坐标和参考点。** 默认主轴侧，明确指定时用副轴侧。端面为 `Z0` 时，按我的约定，主轴侧入料为 `+Z`，副轴侧入料为 `−Z`，当前工件或旧例有明确定义时沿用该定义。写坐标前确认平面、观察方向、单位、X 直径或半径制及刀尖、刃角或刀心参考点。用槽刀时还要标出刀宽朝哪边伸、另一刃会到哪里。
3. **用同一套编号把刀路算清。** 先列 `点号｜位置或动作｜绝对坐标｜数字来源`，再按走刀顺序列 `起点→终点｜带符号的增量｜对应程序地址`。增量等于终点减该段的实际起点。有图时让图、表、程序说明共用点号。区分成品轮廓和刀具轨迹。X 为直径时，按 `r = X ÷ 2` 计算实体尺寸和径向位移。
4. **只贴当前要看的程序。** 先交代入口位置、必要模态和补正状态，再讲「从哪开始 → 怎样走 → 留下什么 → 到哪里」。普通 X/Z 走刀在本机指令支持时优先用 `U/W`，固定入口、退刀点及需要绝对坐标的指令按实际用法写。圆弧按当前平面、刀台和规定视图选 `G02/G03`。未知刀号、`S/F`、M 码及退让位置列在代码外，先完成能确定的部分。
5. **从程序反算一遍。** 用实际起点加增量还原各段终点，查圆弧半径和相切、刀宽覆盖、进退刀、循环返回以及下一段继承的模态。双通道分别跟踪主副轴状态，逐项查等待、夹紧反馈、旋转/位相/Z 同步、切断、退让和首末件分支。算术与几何核查、程序审阅、控制器仿真、实机空运行、首件实测各自记录证据与待核项。尺寸偏差从图纸目标、实测、刀具与装夹状态开始，确认补正单位和方向后再定修正量。

## 新写程序时的默认约定

- 逐道工序按材料、刀具、加工方式和机台限制填写转速 `S` 与进给 `F`。区分主轴和动力头，区分 `G98` 的 mm/min 与 `G99` 的 mm/rev。条件未齐时写明假设及试切参考值。
- 按计算好的实际刀位编程，保持 `G40`。按干加工编写，按实际刀具刃向选独立的正转或反转指令，核对通道和 M 码，避免带切削液的组合指令。
- 每道工序完成且退刀后，单独写一行 `M01;`，下一行写 `(----------)`。双通道先完成该次同步交接、夹持与退让，再设停点。

旧例的逐行注释保留原代码。把旧例改成新程序时，再按上述约定重新计算刀位和核对工序入口、出口。

## 两个常用写法

- **铣腰孔、腰台。** 腰孔刀心向内偏，腰台刀心向外偏，按本件刀径重算。直线用 `G01`，圆弧用 `G02/G03` 写刀心终点和实际刀心半径 `R`。每端半圆拆成两段 90°，左右最外点各一行。X 按本机已确认的直径制或半径制写。要看动作时用现有动图，追问数值时回到同名点位。 [腰孔刀心轨迹](../output/腰孔铣削_刀心轨迹.gif) · [腰台刀心轨迹](../output/腰台铣削_刀心轨迹.gif)
- **算普通 60° 螺纹。** 沿用我确认的计算公式，写清代入值、单位和起算直径。车螺纹时区分直径差与径向牙深，多头螺纹同时标螺距和导程。 [螺纹计算](../专用技能/cnc-coach/references/drawing-to-production.md#螺纹计算)

## 用已学过的台阶件检查一遍

我问「D 段接 E1，为什么要重新定位？」就从这两个位置讲起。D 段结束于槽刀参考角的 `X16.000 Z14.200`。E1 的 `X16.000 Z15.700` 是外圆刀的入口。两点相差 `1.500 mm`，对应本练习的槽刀宽。整合程序时先为外圆刀建立 E1 入口，再核实际换刀和接近路径。 [双头内螺纹台阶件分段核查](../双头内螺纹台阶件学习/分段刀路代码/代码核查说明.md#覆盖的分段)

## 怎么停、怎么接上

- 聊天里保留当前的问题、关键点表和程序行。看不懂时回到那个点、那个动作或那个算式，必要时换成局部图或动图。
- 我说「保存」时，把已确认条件、图、点位、代码和待核项放进对应专题。刀宽、基准或尺寸改了，沿用同一编号，同步更新受影响的图、表、程序和核查记录。未完成的机床草案用 `.nc.txt` 标明教学或审阅状态。
- 跨聊天续学时留一行进度，格式为 `工件／通道／工序／停在哪个点或哪行／已确认条件／下次从哪里接`。

下次可以直接说 **「按我的加工学习工作流，接着讲这道工序。先标绝对点，再算带符号的增量，只贴这一段代码。」**
