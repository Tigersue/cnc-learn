# 津上走心机 G 代码速查

按编号查。每条只看**格式、参数、最短例子**。方括号表示可省略，X(U) 表示绝对 X 或增量 U，Z(W) 同理。例子按各题的坐标和刀位阅读，属于独立教学片段。

### G01　直线、倒角和圆角

**格式**　`G01 X(U)… Z(W)… F…`。支持直接图纸尺寸输入时，可用 `G01 X… ,A… F…` 或在理论拐点段加 `,C…`、`,R…`。  
**参数**　X/Z 是终点，F 是进给。A 是斜线角度，C 是倒角尺寸，R 是圆角半径。自动 C/R 要接下一段直线。  
**最短例子**　从 X14/Z7 写 `G01 X16.0 Z8.0 F0.05`，径向与轴向各走 1 mm，形成 C1。若按 +Z 朝 +X 计正角，也可写 `G01 X16.0 ,A45.0 F0.05`。自动倒角例从 X12/Z0 写 `G01 X16.0 Z0.0 ,C1.0 F0.05`，下行 `G01 Z5.0`。同一理论拐点改用 `,R1.0` 即插入 R1。

### G02　顺时针圆弧

**格式**　`G02 X… Z… R… F…`  
**参数**　X/Z 是终点，R 是实际圆弧半径。顺时针按机台刀台与轴向图判。  
**最短例子**　按双头件练习的刀台视图，从 X10/Z6.4 写 `G02 X11.2 Z7.0 R0.6`，接出肩根 R0.6，F 已设。

### G03　逆时针圆弧

**格式**　`G03 X… Z… R… F…`  
**参数**　X/Z 是终点，R 是实际圆弧半径。逆时针按机台刀台与轴向图判。  
**最短例子**　按双头件练习的刀台视图，从 X16/Z11.5 写 `G03 X15.0 Z12.0 R0.5`，接出槽口 R0.5，F 已设。

### G07.1　圆柱插补

**格式**　`G07.1 C半径` 开启，`G07.1 C0` 取消，各自单独一行。  
**参数**　开启行的 C 填工件半径。走刀行的 C 在本例填角度，Z 填轴向终点。  
**最短例子**　Ø20，槽起点 Z0/C0，已设 Z–C 插补平面、G98 和 G01 模态。

```gcode
G07.1 C10.0
G01 Z-20.0 C180.0 F80
G07.1 C0
```

端面为 Z0、同一条槽从端面内 3 mm 开始时，按本题负 Z 入料，走 Z−3 到 Z−23。

### G32　车一段同步螺纹

**格式**　`G32 Z(W)… F…`，斜进或锥线可同时给 X(U)。  
**参数**　Z/W 是终点或轴向位移，F 是导程。切入、退刀、返回分别编写。  
**最短例子**　M8×1.25 已在 X7.550/Z−2，写 `G32 W10.0 F1.25`，同步车到 Z8。

### G40 / G41 / G42　刀尖圆弧半径补正

- **格式**：`G41` 刀尖 R 左补正，`G42` 刀尖 R 右补正，`G40` 取消补正（均须配合有效直线 `G00/G01` 生效或取消，不可放在圆弧段）。
- **参数**：`OFS/SET` 形状补正填入刀尖圆弧半径 `R` 与假想刀尖方向号 `T`（`1`～`8`），且 `T□□○○` 后两位 `○○` 不能为 `00`。
- **判断与速记**：站在成品轮廓线上、脸朝刀相对工件前进方向：刀尖圆心在**左手边用 `G41`**，在**右手边用 `G42`**。津上前刀台往 `+Z` 车外圆用 `G41 + T4`；外向内车端面倒角用 `G42 + T4`；后车刀往 `-Z` 拉车用 `G42 + T3`。详查 [G41_G42 刀尖 R 补正讲解与调机指南](../G41_G42刀尖R补正学习资料/G41_G42刀尖R补正讲解与调机指南.md)。
- **最短例子**：前刀台 `T4` 从 `X8.0 Z-1.0` 建补正精车 C1 倒角，写 `G41 G01 X10.0 Z0.0 F0.05`，轮廓走完稳刀后写 `G40 G01 U3.0` 退刀取消。

### G66　移动后调用宏

**格式**　`G66 P宏程序号 [L重复次数] [宏参数]`  
**参数**　P 指向 O 程序。登记后，后续移动段执行完才调用宏。  
**最短例子**　`G66 P7032`，下一行 `G00 X10.050`。到 X10.050 后调用 O7032。斜进版宏再走 U−2.500，实际切牙 X 是 7.550。

### G67　取消 G66

**格式**　`G67`  
**参数**　单独一行，无地址参数。  
**最短例子**　螺纹各刀完成后先写 `G67`，再写工序退刀移动，退刀段就不会再调用 O7032。

### G70　按轮廓精车

**格式**　`G70 P轮廓首段 Q轮廓末段`  
**参数**　P/Q 填 N 段号，精车进给读轮廓段里的 F。  
**最短例子**　下方 G71 粗车结束后写 `G70 P100 Q140`，按同一轮廓的 F0.06 精车。

### G71　按轮廓分层粗车

**格式**　`G71 U切深 R退刀量`，下一行 `G71 P首段 Q末段 U直径留量 W轴向留量 F粗车进给`。  
**参数**　第一行 U 是单边切深。X 直径编程时，第二行 U 是直径留量。P/Q 指向成品轮廓。  
**最短例子**　Ø20 棒料，从 X22/Z−1 开始，+Z 入料，G99。U1.0 单边切 1 mm，U0.4 单边留 0.2 mm。

```gcode
G71 U1.0 R0.5
G71 P100 Q140 U0.4 W-0.1 F0.12
N100 G00 X12.0
N110 G01 Z10.0 F0.06
N120 X16.0
N130 Z20.0
N140 X21.0
```

### G74　沿 Z 啄切

**格式**　`G74 R小回退`，下一行 `G74 X(U)… Z(W)… P… Q… R… F…`。  
**参数**　Q 是 Z 每啄量，P 是 X 径向列距。单列省 X/U 和 P。第二行 R 是到槽底后的 X 向让刀量。  
**最短例子**　从 X16/Z−1 写 `G74 R0.2`，下一行 `G74 Z4.0 Q1000 R0 F0.03`。按 0.001 mm 输入单位，每啄 1 mm。

### G75　沿 X 啄切

**格式**　`G75 R小回退`，下一行 `G75 X(U)… Z(W)… P… Q… R… F…`。  
**参数**　P 是 X 每啄径向量，Q 是 Z 列距。单列省 Z/W 和 Q。第二行 R 是到槽底后的 Z 向让刀量。  
**最短例子**　从 X22/Z10 写 `G75 R0.2`，下一行 `G75 X14.0 P500 R0 F0.04`。按 0.001 mm 输入单位，每啄径向 0.5 mm，槽底 Ø14。

### G76　自动分多刀车牙

**格式**　`G76 P(m)(r)(a) Q最小切深 R精车余量`，下一行 `G76 X牙底 Z终点 R锥度 P牙高 Q首刀切深 F导程`。  
**参数**　首行 P 六位拆成精车次数、退尾量、刀尖角。切深、牙高和首行精车余量按径向量读。首行 Q 和次行 P/Q 按整数输入单位。  
**最短例子**　M10×1.5 教学例，P020060 拆成 02 / 00 / 60。按 0.001 mm 单位，Q50 是最小切深 0.05 mm，P920 是牙高 0.92 mm，Q250 是首刀 0.25 mm。

```gcode
G76 P020060 Q50 R0.05
G76 X8.160 Z16.5 R0.0 P920 Q250 F1.5
```

### G80　取消开孔固定循环

**格式**　`G80`  
**参数**　单独一行，无地址参数。攻丝循环本身已完成反转退出。  
**最短例子**　`G84 Z6.0 P100 F1.25`，下一行 `G80`，再写后续定位。

### G84　端面中心刚性攻丝

**格式**　`M29 S…`，下一行 `G84 Z(W)… [R…] [P…] F…`，结束用 `G80`。  
**参数**　S 是转速，Z 是攻丝终点，R 管初始面到 R 点的距离，P 是孔底延时，F 是导程。用 G99。  
**最短例子**　主轴端面已对中心，`M29 S600` → `G84 Z6.0 P100 F1.25` → `G80`。P100 的时间按机台规格核对。

### G90　沿 Z 车外圆或内孔

**格式**　`G90 X(U)… Z(W)… F…`，直线型。  
**参数**　X 是本刀直径，Z 是轴向终点，F 是切削进给。每刀回到循环起点。  
**最短例子**　从 X18/Z−1 写 `G90 X16.0 Z10.0 F0.25`，下行 `X12.0`，第二刀仍车到 Z10，直径改成 Ø12。

### G92　自己给每刀深度

**格式**　`G92 X(U)… Z(W)… F…`，直螺纹。  
**参数**　X 是本刀车牙直径，Z 是终点，F 是导程。外牙加深 X 递减，内牙加深 X 递增。  
**最短例子**　M6×1 从 X7/Z−2 写 `G92 X5.40 Z6.5 F1.0`，下行 `X4.96`，第二刀沿用 Z 和 F。

### G94　沿 X 车端面

**格式**　`G94 X(U)… Z(W)… F…`，直线型。  
**参数**　Z 定每刀的端面位置，X 定径向切削终点，F 是切削进给。  
**最短例子**　从 X16.6/Z−1 写 `G94 X8.0 Z4.0 F0.05`，下行 `Z8.0`，第二刀在 Z8 处车至 X8。

### G184　前动力头横向攻丝

**格式**　`M129 S… Q方向`，下一行 `G184 X(U)… [R…] [Q延时] F…`。  
**参数**　X/U 是攻丝终点，R 给进刀起点，均按直径量。用 U 时 R 改填距循环起始点的距离。M129 的 Q 选旋向，G184 的 Q 是孔底延时，按秒带小数点。G99，F 写导程。  
**最短例子**　津上 T02 原例，`M129 S1000 Q-1` → `G184 X5.0 R20.0 Q1.0 F1.0`。从 R20 到 X5，实际攻入 7.5 mm。

### G185　背驱轴向攻丝

**格式**　`M129 S…`，下一行 `G185 Z… P… F…`，结束用 `G80`。  
**参数**　你给的 TF-Plus 图中，副轴夹工件，背驱带丝锥转，沿 Z2 攻。Z 是终点，P 是孔底延时。G99，F 写导程。  
**最短例子**　`M129 S600` → `G185 Z-5.0 P100 F1.0` → `G80`。

### G186　背面动力头横向攻丝

**格式**　`M129 S… Q方向`，下一行 `G186 Y(V)… [R…] [Q延时] F…`。  
**参数**　背轴侧 Y2，Y/V 是攻丝终点，R 给进刀起点，均按半径量。用 V 时 R 改填距循环起始点的距离。M129 的 Q 选旋向，G186 的 Q 是孔底延时，按秒带小数点。G99，F 写导程。  
**最短例子**　按津上手册格式页自拟，确认旋向并执行 M129 后写 `G186 Y8.0 R12.0 Q0.5 F1.0`。R12 到 Y8 是实际 4 mm，孔底延时 0.5 秒。

### G284　前动力头侧孔攻丝

**格式**　`G17` → `M129 S…` → `G284 X… P… F…` → `G80`。  
**参数**　按你给的 TF-Plus 图，X 是侧孔攻丝终点，P 是孔底延时。G99，F 写导程。  
**最短例子**　`G17` → `M129 S600` → `G284 X2.0 P100 F1.0` → `G80`。

### G285　主轴持件，一拖三轴向动力头攻丝

**格式**　`M129 S…`，下一行 `G285 Z… P… F…`，结束用 `G80`。  
**参数**　按你给的 TF-Plus 图，Z 是攻丝终点，P 是孔底延时。G99，F 写导程。分层时，每一层各写一行完整循环。  
**最短例子**　`M129 S600` → `G285 Z5.0 P100 F1.0` → `G80`。分层例把 Z 分别写成 2、4、6、8。
