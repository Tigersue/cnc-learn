## 1. 看图和定基准

工件是 Ø16 × 40 的圆柱。图注 `M6*1.0-9个全是`。按端视图和纵向投影配对，左端两个偏心孔对应 15 mm，右端三个偏心孔对应 10 mm。由总数减去两端的 5 孔，结合侧视图，外圆中部按 4 个螺纹孔口识读。侧孔中心站位距端面 20 mm。材料栏为“未指定”。图中未定端孔偏心距、各组实际分度、侧孔深度和连通方式，15、10 的深度类型也要确认。

```text
图上左端 A                    外圆中部 S                     图上右端 B
2 个端面孔 ────── 20 ────── 4 个侧孔口 ────── 20 ────── 3 个端面孔
Z1 = 0                     Z1 = +20                       Z1 = +40
                                                            Z2 = 0
主轴 Z1 向图上右侧为正。副轴 Z2 另起零点，B 端向零件内部为负。
```

纸面几何换算为 `Z1 = 40 + Z2`。例如 B 端钻尖 `Z2−11.502` 对应主轴尺度 `Z1+28.498`。实际程序各用自己的刀具补正和工件零点。X1、X2 按直径编程，孔位和刀具对中均用实际刀具轴线。

## 2. 本稿采用的教学条件

| 项目 | 本稿用值及来源 |
|---|---|
| 毛坯和切断 | 设 Ø17 棒料，车到 Ø16 的径向余量为 0.50 mm。按工件侧刃角对刀，在主轴 `Z40.20` 切断，副轴精车 0.20 mm 后成品长 40。刀宽向棒料侧占用，按实际刀宽校核。 |
| 两端孔距 | A、B 端均假设偏心半径 4.0 mm，孔转到刀具 X 正侧，孔心 `X8.0`。A 端相对角 0°、180°，B 端相对角 0°、120°、240°。 |
| 侧孔结构 | 假设两条正交对穿底孔。按 0°、90° 钻通，按 0°、90°、180°、270° 从各自入口倒角和攻丝。各孔口的丝锥参考点深入 5.0 mm。 |
| 深度 | 本稿把 15 和 10 暂按 Ø5 底孔的完整圆柱深度演算。选 118° 钻尖，A、B 丝锥参考点分别进 14、9 mm，圆柱底各余 1 mm。丝锥前端到首个完整牙的距离、实际完整牙长和底部容屑空间按刀具另核。 |
| 孔口和丝锥 | Ø5 底孔用于切削丝锥的演算。孔口用 90° 锥刀，按虚拟尖对刀，端面孔口演算直径 Ø6.2。丝锥用 M6×1.0 普通单头，`G99 F1.0`。 [OSG 底孔实例](https://www.osg.co.jp/media_dl/flier/file/p_26.pdf) |

程序里写出的 C 是各组相对角。转换时按 `实际 C = 对应组首孔的机床角 + 该通道方向系数 × 表中相对角` 计算，角度按控制器适用范围归一。钻孔、倒角和攻丝换刀后都要回到同一孔轴。A、S、B 三组首孔与工件实际基准的关系仍需确定，副轴接料后的首孔基准单独核对。

**标准 S205A 前横向动力头最大攻丝径为 M5。** 四个 M6 侧孔的 `G284` 行保留作纸面练习。实做须先确认所装横向动力头和对应配置明确支持 M6。两端采用动力头带丝锥转，夹持工件的轴做 C 定位。A 端用图中主轴一拖三轴向动力头 `G285`，B 端用背驱轴向动力头 `G185`，两者的偏心可达范围和攻丝能力均按实装核对。

| N020 | 主轴外圆刀，车 Ø16 | `X16 Z−1 → X16 Z40.2 → X18，Z−1` |
| N030 | 主轴侧轴向 Ø5 钻，2 孔 | `X8 Z−2 → Z6 → Z11 → Z16.502 → Z−2`，每级按程序退出和重新接近 |
| N040 | 主轴侧轴向 90° 锥刀，2 孔口 | `X8 Z−2 → Z3.1 → Z−2` |
| N050 | 主轴侧轴向 M6 丝锥，2 孔 | `X8 Z−2 → Z14 → Z−2`，`G285` |
| N060 | 横向 Ø5 钻，2 条对穿孔 | `X20 Z20 → X4 → X−8 → X−20 → X20`，每级按程序退出和重新接近 |

| N090 | 切断刀，副轴已夹紧 | `X18 Z40.2 → X−0.5 Z40.2`，纸面径向退回 `X18`，按实机交接安排顺序 |

## 4. 关键增量怎么算

| 切削段 | 起点 → 终点 | 程序量 |
|---|---|---|
| 两端平面和切断的 X 切削 | `18.0 → −0.5` | `U−18.5`，实际径向走 9.25 mm |
| 外圆 | `Z−1.0 → Z40.2` | `W+41.2` |
| A 端最后一钻 | `Z10.0 → Z16.502` | `W+6.502` |
| B 端最后一钻 | `Z−7.0 → Z−11.502` | `W−4.502` |
| 侧钻切削，三次分段 | `X20 → X4`、`X6 → X−8`、`X−6 → X−20` | `U−16.0`、`U−14.0`、`U−14.0` |
| 侧攻丝，绝对终点 | 外圆名义孔口 `X16 → X6` | 直径减 10，径向深入 5 mm。循环写 `G284 X6.0` |

- **钻尖比孔底深。** Ø5、118° 的理想钻尖高为 `2.5 ÷ tan59° ≈ 1.502` mm，因此两端钻尖深是 16.502、11.502。侧钻尖从近侧孔口穿到远侧外圆后再走 2 mm，`X−20` 在此模型中可让 Ø5 全径通过。第二条横孔中间会切入第一条已钻的空腔，重新入刃和出孔的进给、钻头伸出及远侧空间要现场核对。
- **曲面孔口的倒角深度。** 平端面上用虚拟尖进 3.10 mm 可得理论口径 Ø6.20。侧孔要让圆周方向两侧各到 3.10 mm，先扣掉圆柱面下沉量 `8−√(8²−3.1²)≈0.625` mm。虚拟尖径向进 `3.10+0.625=3.725` mm，终点 `X≈8.550`。外圆侧孔的口缘沿圆周和轴向宽度不同，现场按图纸最终要求和真实锥刀核对。
- **确认孔间余肉。** 按教学偏心半径 4.0 和端面孔口 Ø6.2，端面外缘最薄处名义为 0.9 mm，A 组两孔口净距 1.8 mm，B 组约 0.73 mm。A 组钻尖最深 `Z1=16.502`，中部 Ø5 底孔最靠近 A 端到 `Z1=17.5`。侧孔倒角在外圆处轴向范围更宽，靠 A 端的极限区仍位于外缘，和 A 端钻尖包络分开。侧丝锥尖到 `X6` 时距中心还有 3 mm，垂直底孔在本方向延伸到距中心 2.5 mm，名义间隔 0.5 mm。若 15 mm 实为有效牙长，重新算攻丝和底孔深度，再查与侧孔的交界。

## 5. 接料与核对

主轴完成 A 端和侧孔后，副轴夹持 A 端的已车外圆。核对夹持带、夹持变形、刀宽和刀架退让，再按实际模板建立等待、回转同步和夹紧完成条件。零件有孔系相位关系时，还要确认接料后的角度对应。按成品侧刃口 `Z40.2` 切断，副轴建立 B 成品面零点并精车到总长 40，随后执行 B 端三孔。夹持、同步和角度传递数据留在程序的工序入口，使用现场模板补齐。

车削和切断用 `G99`，普通动力头钻孔及倒角用 `G98` 和 mm/min，三种攻丝显式切回 `G99 F1.0`。逐孔核对 C 轴保持、循环反转退出、`G80` 和分度退让。侧攻丝使用 `G17`，车削段显式重设 `G18`，轴向动力头段按对应 TF-Plus 配置核实平面。T、普通切削 F、S、P、换刀退让和接料参数要按实装填入。首件按实际要求查 Ø16、总长 40、孔位置、完整牙长与 M6 螺纹通止。

已核查刀路算术、孔数和模态衔接。控制器仿真、空运行及首件实测待有实际机台和刀具数据后进行。
