# S205A TF-Plus 九孔刚性攻丝练习

纸面编程练习。**9 个 M6×1.0 都写 `G99`、`F1.0`，按孔的方向和夹持位置分三段。** 手册列出的标准前横向动力头最大攻丝径为 M5，本件侧孔 M6 超出该规格。侧孔段用于练习 `G284` 的格式，实做需要有明确支持 M6 的加工配置。

## 1. 先数孔，再定零点

图纸标注“`M6*1.0-9个全是`”，外圆 Ø16，总长 40，材料未指定。按视图对应关系，左端是两孔端，右端是三孔端，剩余四个孔口位于外圆中部。图上 15、10 分别对应两端的轴向孔深标注，侧孔中心距端面 20。孔深标注的具体含义、端孔中心坐标、各组相位和侧孔内部连通情况需确认。

| 孔组 | 数量 | 练习选定的夹持和基准 | 按 TF-Plus 格式图选用 |
|---|---:|---|---|
| A，两孔端 | 2 | 主轴持件，两孔端面 `Z1=0`，向里为正 | `G285`，后驱一拖三的轴向动力头转丝锥，沿 Z1 攻入 |
| S，外圆中部 | 4 | 主轴持件，孔轴所在截面 `Z1=20.0` | `G284`，前横向动力头转丝锥，沿 X1 攻入 |
| B，三孔端 | 3 | 副轴持件，三孔端面单独建立 `Z2=0`，向里为负 | `G185`，背驱轴向动力头转丝锥，沿 Z2 攻入 |

格式图的两段 `G84` 由夹持工件的主轴或副轴带工件转，例程均在 `X0` 攻中心孔。这五个端面孔都偏心，应先用 C 轴把孔转到丝锥能对准的位置，定位保持后由动力头转丝锥。轴向动力头的实际安装、偏心位置可达性和攻丝能力按机台配置核实。

## 2. 把孔位、孔口和攻丝终点分开

表中的分度只用于纸面推演。假设每组内等分，以各组第一孔为相对零位。正式 C 坐标还需加上各组首孔对机床的实际角度，并按对应通道的 C 正向换算。主副轴接料后要核对三孔端的角度基准。

| 孔组 | 组内角度练习 | 孔口位置 | 丝锥参考点的循环终点 |
|---|---|---|---|
| A1、A2 | 0°、180° | `Z1=0`。C 转到刀具所在径向平面后，按实际孔心定位 X | `Z1=+dA` |
| S1 至 S4 | 0°、90°、180°、270° | `Z1=20.0`。假设孔轴沿径向，X 为直径编程，从 X 正侧进刀，名义孔口 `X1=16.0` | `X1=16.0−2dS` |
| B1 至 B3 | 0°、120°、240° | `Z2=0`。C 转到刀具所在径向平面后，按实际孔心定位 X | `Z2=−dB` |

`dA`、`dS`、`dB` 是从各自孔口量起的丝锥参考点攻入量。端面孔若确认等半径分布，并且孔被转到 X 方向上，则孔心的 X 直径读数绝对值为 `2×偏心半径`。侧孔从 `X16.0` 进到 `X14.0` 时，`ΔX=−2.0`，丝锥实际攻入 1 mm，所以每转 1 mm 仍写 `F1.0`。

若确认 15 和 10 是有效牙长，要按丝锥图确定导入段和端口倒角占用的长度，再定循环终点。对盲孔，底孔的完整圆柱段还要给丝锥前端与孔底留空间，钻尖终点另算。两孔端的标注深度 15 与侧孔中心站位 20 在轴向只差 5 mm，底孔加深前应结合真实孔位核查是否与侧孔相交。侧孔是各自盲孔还是对穿孔的两侧孔口，也会改变底孔和攻丝终点。

## 3. 每组写一孔，再按孔位表分度

尖括号是待填数据。以下为不可执行的格式骨架。沿用指定图片中的 `G285/G284/G185`、`M129` 和 P 地址。图片的 `S600`、`P100`、T 号和退让坐标属于例程。实际转速、P 值及单位、刀号、刀补和退让位置由适用资料和装机条件确定。

| 图中的准备与退出 | C 分度前的示例顺序 | 加工结束后，刀具退清再执行 |
|---|---|---|
| 主轴持件，A 或 S | `M223 S0 → M50 → M225 → G28 H0.0 → G00 C… → M82` | `M83 → M51` |
| 副轴持件，B | `M123 S0 → M150 → M125 → G28 H0.0 → G00 C… → M182` | `M183 → M151` |

这两行保留格式图的顺序，机台所装动力头及制动选配决定适用的 M 码。H 回参考点和首次分度也应在刀具退清时进行。

**A 组，两孔端，主轴持件。** 参照图片右列。按实装刀具在安全位置选刀，主轴切换到 C 轴定位模式，分度到本孔角度，按机台配置保持工件角度。先确认 Z 在端面外，按孔位对准 X。

```text
G99
M129 S<轴向动力头转速>
G285 Z<+dA> P<孔底延时指令值> F1.0
G80
G00 Z<已核实的负侧退让位置>
```

**S 组，四个侧孔，主轴持件。** 参照图片“主轴侧面刚性攻丝”列。纸面顺序为在安全 X 位置定位 `Z20.0`，C 分度并保持角度，再将横向丝锥对准孔口外的起点。

```text
G99
G17
M129 S<横向动力头转速>
G284 X<16.0−2dS> P<孔底延时指令值> F1.0
G80
G00 X<已核实的外圆退让位置>
```

**B 组，三孔端，副轴持件。** 参照图片“背轴驱动刚性攻丝”列。练习顺序为接料和切断完成后，建立三孔端局部零点，在安全位置选轴向背驱刀，副轴 C 分度并保持角度，从端面正侧对准偏心孔。

```text
G99
M129 S<背驱轴向动力头转速>
G185 Z<−dB> P<孔底延时指令值> F1.0
G80
G00 Z<已核实的正侧退让位置>
```

每孔均按“对准 → 同步攻入 → 反转同步退出 → `G80` 取消 → 退到分度安全位置”的顺序核对。装有 C 轴制动的配置，换孔时先确认刀具已退出，再解除制动、分度并重新保持。三段有各自的入口条件。侧孔段用了 `G17`，`G80` 后平面选择仍然保留，切换工序前要确认下一段需要的平面和进给轴。主副轴间还须核对接料夹持、相位和退让，才能把三段接入整件程序。

加工每组前先做对应底孔及孔口。切削丝锥的底孔可从 Ø5.0 的厂家示例理解，最终按所选丝锥、材料和牙型要求定。挤压丝锥另查适配底孔。 [OSG 切削丝锥与挤压丝锥的底孔对照](https://www.osg.co.jp/media_dl/flier/file/p_26.pdf)
