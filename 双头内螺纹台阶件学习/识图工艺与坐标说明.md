# 双头内螺纹台阶件：识图、工艺与分段编程

状态：学习用几何与工艺草案。已做独立读图和几何复核，未做控制器仿真、实机干涉检查或首件试切。

## 当前确认与教学约定

- 用户确认机型背景为津上S205A/S206A；具体机型、控制器版本、刀台/通道及实际Z方向待补充。
- 用户确认11.50左尺寸界线接R0.50与φ16相切处，因此总长为30.20 mm。
- 用户确认M10×1两头螺纹中的1是螺距。因此头数2、螺距P=1、导程Lh=2 mm。
- 用户补充凸台靠φ10一侧为C1，即1×45°倒角；左孔10为“有效孔深”。本稿将有效孔深解释为底孔全直径部分深10，不把它写成完整有效牙深。
- 本稿统一采用：右侧φ10端面Z0、向图纸左侧+Z；X用直径值，X0为轴线，毫米。在实体几何计算中r=X/2。
- 所有外轮廓点是成品几何点。未将它们冒充真实圆刀尖的刀位；槽刀另列有限刀宽换算。
- 左右两端C/R按“C为45°理论倒角尺寸，再将斜面与外圆交接处修R”解释；该几何解释应与原CAD核对。

## 2. 先建立轴向尺寸链

把11.50的左基点认准，它在槽右壁的右侧0.50处。先从这个切点回到槽壁：

```text
槽右壁Z = 11.50 + 0.50 = 12.00
φ10肩面Z = 12.00 - 5.00 = 7.00
槽左壁Z = 12.00 + 3.20 = 15.20
左端面Z = 15.20 + 15.00 = 30.20
总长 = 15 + 3.20 + 0.50 + 11.50 = 30.20
```

5这一段已经在上述尺寸链里定位肩面，不能又把它作为独立全长段加进总长。

端面Z0是编程几何基准，不是在此要求修改机床机械原点。

## 3. 工艺先按加工面分组

下面是一条走心机候选路线，实际夹持和背面能力尚未核定；保留同机主副轴方案，不强制改成二次装夹。

| 工序 | 目的 | 选刀/前提 |
|---|---|---|
| 主轴侧端面、外形粗车 | 建立右端面；保留足够材料刚性 | 外圆/端面刀；棒径和粗车分刀按毛坯、材料及刀具确定 |
| 主轴侧精车φ10、肩根和凸台C1 | 建立接料候选表面和肩面 | 可达相应肩面的刀具；C1轮廓端点已补齐，实际刀尖补偿另核 |
| 主轴侧环槽粗加工、精加工四R及φ12 | 槽放在较大负荷外圆粗车之后，减少细颈受力 | 允许侧向加工的槽刀；核刀宽、两刃R、对刀参考角 |
| 主轴侧左φ16直外圆精加工 | 完成槽到大端外圆 | 左端最终C/R可留到背面修面后完成 |
| 副轴接料、切断 | 切断后大端面可被背面刀具接近 | φ10是候选夹持区；夹持长度、夹紧力、切断刀宽、余量与同步均待实际条件确认 |
| 背面修大端面及左C/R | 保证30.20总长和大端外缘 | 以同一总长链建立背面局部坐标 |
| 背面钻底孔、处理孔口、双头内螺纹 | 从图左端加工盲孔 | 核背面钻攻/螺纹能力、刀具及孔深；孔口加工量不能擅改图纸 |
| 检验、去毛刺 | 检查关键尺寸及有效螺纹 | 双头螺纹匹配的量规/检验方案 |

若小端C/R采用本稿解释，φ10平直段为Z1.022843至Z6.40，长5.377157 mm。这只是几何可见长度，不能直接认定可供副轴有效夹紧5.38 mm；还要扣除夹头倒角、靠肩及退让等实际限制。

若背面没有适合该双头盲螺纹的加工能力，需要重新评估让大端孔优先在主轴加工的装夹方案；不能仅凭型号背景断言可以攻M10。

## 4. 四个R0.50怎样算

90°相切圆角沿相邻直线各占R=0.50；径向变化0.50在X直径中为1.00。

从图右向左走，点均为(X直径,Z)：

| 点 | 坐标 | 来源 |
|---|---|---|
| A 槽右口外圆切点 | (16,11.50) | 用户确认的11.50基点 |
| B 右壁上切点 | (15,12.00) | X=16−2×0.50；Z=11.50+0.50 |
| C 右壁下切点 | (13,12.00) | X=12+2×0.50 |
| D 右槽底切点 | (12,12.50) | Z=12+0.50 |
| E 左槽底切点 | (12,14.70) | Z=15.20−0.50 |
| F 左壁下切点 | (13,15.20) | X=12+2×0.50 |
| G 左壁上切点 | (15,15.20) | X=16−2×0.50 |
| H 槽左口外圆切点 | (16,15.70) | Z=15.20+0.50 |

连接顺序：A—R0.50—B—直线—C—R0.50—D—直线—E—R0.50—F—直线—G—R0.50—H。

```text
直槽底长 = 14.70−12.50 = 3.20−2×0.50 = 2.20
槽口切点间距 = 15.70−11.50 = 3.20+2×0.50 = 4.20
从φ16到φ12的单边槽深 = (16−12)/2 = 2.00
```

圆心用(Z,r)表示依次为(11.50,7.50)、(12.50,6.50)、(14.70,6.50)、(15.70,7.50)。在实体半径平面检查R，不能用直径X直接当纵向实体长度检查圆度。

## 5. 槽刀刀宽必须另算

先用一般式：刀宽b，靠图右的低Z刃角作参考，刀具覆盖[Zref,Zref+b]。则右侧用低Z刃控制轮廓，左侧用高Z刃控制轮廓。

仅作教学，假设b=1.50 mm、两刃为理想零R、刀具允许侧向车槽；这不是现场刀具数据。

| 动作 | 成品控制刃坐标 | 低Z参考角的Z |
|---|---:|---:|
| 右壁 | 12.00 | 12.00 |
| 右槽底R终点 | 12.50 | 12.50 |
| 左槽底R起点 | 14.70 | 14.70−1.50=13.20 |
| 左壁 | 15.20 | 15.20−1.50=13.70 |
| 左槽口外圆切点 | 15.70 | 15.70−1.50=14.20 |

所以刀片平底覆盖整个2.20长直底时，参考点只需从12.50走到13.20，即0.70；这0.70是2.20减刀宽1.50，不是槽宽变成0.70。

真实刀尖R不为零时，需重算刃角参考轨迹。不能把这里的成品R0.50一律加/减刀尖R，或把成品轮廓表直接给槽刀走一遍。

## 6. φ10肩根R0.60

理论尖角为(X10,Z7)。半径0.60沿圆柱占轴向0.60，沿肩面占径向0.60：

```text
圆柱切点：(X10,Z7−0.60) = (X10,Z6.40)
肩面切点：(X10+2×0.60,Z7) = (X11.20,Z7)
圆心(Z,r)：(6.40,5.60)
```

用户补充凸台外角为C1，即径向和轴向各占1.00。X是直径值，所以径向1.00对应X变化2.00：

```text
肩面端点：(X16−2×1,Z7) = (X14,Z7)
外圆端点：(X16,Z7+1) = (X16,Z8)
肩根R出口到C1起点的径向直线长 = (14−11.20)/2 = 1.40
C1结束后到右槽口切点的φ16直线长 = 11.50−8.00 = 3.50
```

因此从肩根R出口继续的成品轮廓为：

```text
(X11.20,Z7) →直线→ (X14,Z7) →45°直线→ (X16,Z8)
→φ16直外圆→ (X16,Z11.50)
```

C1占用原来5.00凸台段内的长度，不增加总长30.20。

## 7. 两端C与R相邻，不能各占一段直接相加

假设C为45°理论倒角，圆角接在倒角与圆柱的交接点。两条直线在转向处改变45°，沿直线的切线退距：

```text
t = R×tan(45°/2) = R×tan22.5°
q = t/√2   （沿45°斜线的轴向、径向投影）
```

### 右端C0.94与R0.20

```text
端面理论直径 = 10−2×0.94 = 8.12
t = 0.20×tan22.5° = 0.0828427
q = 0.0585786
斜面切点Z = 0.94−q = 0.8814214
斜面切点X = 10−2q = 9.8828427
圆柱切点Z = 0.94+t = 1.0228427
圆柱切点X = 10
```

从右面向左走：(X8.12,Z0)→直线→(X9.882843,Z0.881421)→R0.20→(X10,Z1.022843)→直线→(X10,Z6.40)。

### 左端C0.88与R0.40

```text
端面理论直径 = 16−2×0.88 = 14.24
未修圆理论交点Z = 30.20−0.88 = 29.32
t = 0.40×tan22.5° = 0.1656854
q = 0.1171573
圆柱切点Z = 29.32−t = 29.1543146
斜面切点Z = 29.32+q = 29.4371573
斜面切点X = 16−2q = 15.7656854
```

从右向左走：(X16,Z29.154315)→R0.40→(X15.765685,Z29.437157)→直线→(X14.24,Z30.20)。

小数保留6位用于说明计算来源，不代表图纸要求微米以下精度；实际程序位数依控制器分辨率和公差确定。

## 8. 双头盲内螺纹分清三个长度

```text
螺距P = 1 mm
头数n = 2
导程Lh = nP = 2 mm/转
两条螺旋线的圆周相位差 = 360°/2 = 180°
```

导程与螺距关系由刀具厂家技术资料支持：[Sandvik Coromant，Multi-start thread](https://www.sandvik.coromant.com/en-us/knowledge/threading/thread-turning/thread-turning-application-tips)。若车螺纹，沿一条螺旋线每转轴向走2 mm；若用丝锥，需匹配该双头规格，不能拿普通单头M10×1丝锥代替。具体循环格式待当前通道、控制器及刀具确认。

背面定义局部深度s：左成品端面s0，向孔内为+s；这是几何深度，不代表副轴实际NC地址必为正。与本稿全局几何关系：Zglobal=30.20−s。

用户补充10为有效孔深，本稿按底孔全直径深度H=10解释：

```text
完整底孔末端：局部s=10；全局Z=30.20−10=20.20
理想钻尖高度：h=(d/2)/tan(θ/2)
钻尖终点：局部s=10+h；全局Z=30.20−(10+h)=20.20−h
```

d为实际选定底孔直径，θ为实际钻尖角；二者未给，故钻尖终点暂保留公式。有效孔深10不能直接当成钻尖深10，也不证明有10深的完整螺纹。

设a为丝锥前端到能形成完整牙位置的轴向距离，c为依据刀具及盲孔条件确定的底部余量，在本稿保守要求丝锥尖留在完整底孔范围内时：

```text
丝锥尖允许深入量 ≤ 10−c
完整有效牙深 ≤ 10−c−a
```

若还要求完整牙深10，就需要结合设计和刀具重新核定孔底空间，不能擅自把已给的有效孔深加深。实际丝锥前端能否利用钻尖锥底，须依据底孔与丝锥实际包络核算，上式没有把锥底空间计作可用余量。

底孔直径、刀具导入长度、钻尖角及余量未给，所以本稿不猜钻孔或攻丝的终点。若改用内螺纹刀车牙，需另核孔底退刀空间和两头起始相位功能，不能套用丝锥深度关系。
