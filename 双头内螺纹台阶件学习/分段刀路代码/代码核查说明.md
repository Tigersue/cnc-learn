# 两份分段刀路代码的适用条件与核查结果

两份文件由同一组运动数据生成，注释语言不同：

- [详细中文注释版](分段刀路_详细中文注释.nc.txt)
- [简易英文注释版](Segmented_Toolpaths_EN.nc.txt)

它们是含真实G01/G02/G03语法的分段教学阅读文件，不是完整生产程序。文件中仅N开头的行是代码；标题、入口出口和缺项说明是阅读文字。无O程序、主副轴框架、刀号、切削条件、进退刀或夹持动作，不可作为一个文件连续运行。

## 固定的教学条件

- 草案基准保持不变：右侧φ10成品面Z0；向图左为+Z；X为直径；公制；G18。
- 采用津上S205A/S206A手册第299页第一组的等效圆弧方向，按T04～T08等效编程视图讲解。原页有其自身刀号标签；本说明不据标签认定现场已装某刀号。
- 在本图正Z向左、正X向上的对应视图内判圆弧；若另画数值图“Z向右、r向上”，G02对应此数值图逆时针、G03对应顺时针。该说明仅用于核本次转换，不能当通用口诀。
- G40已建立，B/C/E采用理想零刀尖R的成品几何路径。真实圆刀尖和刀具可达性另核。
- D采用教学假设：1.50 mm宽、两刃理想零R、允许侧向车槽，低Z刃角对刀，刀片向+Z伸1.50。
- 所有段的粗加工、刀具补正、进给模式与适用F、主轴和冷却状态须已正确建立。实际Z方向、刀台和镜像状态尚未现场确认。

## 已做的核查

1. 去除英文括号注释后，中文与英文的22行N代码逐行完全相同，含17行运动和5行G18选择。
2. 尺寸链闭合为30.20；C1为X14/Z7至X16/Z8，径向和轴向投影各1.00。
3. 7段圆弧的起终点、实体半径、选用小圆弧及方向核对通过。实体计算使用r=X/2。
4. 1.50槽刀由近刃转为远刃控制的参考位置核对通过：槽底末参考Z13.20、左壁参考Z13.70、左口出口参考Z14.20。
5. 对槽刀轨迹及整个1.50宽刀片作数值采样包络检查，未发现超切成品槽轮廓；前提仍是理想零刃角R及允许侧向加工的刀具。
6. 所有代码坐标四舍五入至0.001 mm。端部理论相切点为无理数，舍入后不再是精确相切；N120圆弧相对精确几何的采样最大位置差约0.000429 mm，N510约0.000315 mm。没有图纸公差，不能据此宣称满足全部尺寸或表面要求。
7. 已由独立审阅核对圆弧选择、两刃换算、模态衔接、缺项和双版本注释一致性。

## 保留的工序

粗车、接料切断、真实副轴坐标、底孔及双头螺纹均已在两份文件末尾列明缺项，没有填入示例S/F、刀号、M码或未经核实的加工终点。

底孔全直径有效深10，其末端对应本稿全局Z20.20。钻尖深度取决于底孔直径及钻尖角；完整有效牙长另定。双头螺纹已确认P1、导程2，但刀具、孔底空间与实际通道能力未定，因此未伪造钻攻/车牙循环。
